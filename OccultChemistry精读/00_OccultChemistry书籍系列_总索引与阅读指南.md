**实测结论（`_复算18` 第九节）：**

- **Lyne 完全不知道 Occult Chemistry 这条线** —— 全书 0 次提及 OC / Leadbeater / Besant / Anu / koilon / 1680
- OC 中译本 **完全没有核自旋概念** —— ortho = 0、para = 0、自旋 = 0、spin = 0
- Smith 与 Phillips **不是独立来源** —— Smith 是 Phillips 的解说者与背书人

**⇒ 四书实际是 3 条独立线，不能互相「印证」：**

```
线 A：OC（1895–1933）        原始档案，微灵视观察记录
线 B：Phillips（1979）+ Smith（1980）  后人理论建构 + 主流科学家再评估
线 C：Lyne（1990s–2000s）    独立圈内主张，不引前三者，也未被前三者引用
```

### ★★ 2.1 「不引用」之外还有一层：「对象就不是同一个」（老师指正 2026-09-12）

> **老师指正原话**：`「以太」把两个不同的东西装在了同一个口袋里。`

**★ 本系列起初只做到「0 引用 ⇒ 不能互相印证」这一步。**
**但老师这句指正指出还有更深的一层：即使有人想硬接，也接不上 —— 因为对象不同。**

**★ 最典型的标本：koilon ↔ Lyne 的 ether**

| | **OC 的 koilon** | **Lyne 的 ether** |
|---|---|---|
| 相态 | 「**绝对均匀和坚固**」（`oc_zh.txt` 第 143 行） | 「**不是固体，而是气体**」（`ether_physics.txt` 第 2731 行） |
| 密度 | 铂的 10⁹ ~ 5×10¹² 倍 | 「**不可想象的稀薄**」（*inconceivable tenuity*，第 2393 行） |
| 组成 | 均匀的「空间之水」 | 「正、负电性物质」（第 2386 行） |
| 与物质的关系 | ★ **物质 = koilon 的缺失** | 以太**与物质共存** |

**★ 而且 OC 自己在第 125 行就承认过这件事：**
> 「这一假说**在一个标题下包含了两组完全不同且相差甚远的现象**……
> 　他们**（也许是不明智的）**将这些状态称为以太，
> 　因此**没有为（另一部分）物质提供一个方便的名称**。」

⇒ **「以太」这个词从一开始就是个装了两样东西的口袋 —— OC 自己也知道。**

**★ 本项目已识别的「同名不同物」清单（每一条都曾造成误判风险）：**

| 词 | 至少有两种所指 | 出处 |
|---|---|---|
| **「以太」** | OC koilon（实心）／OC 的 E1–E4 亚态（物质）／Lyne ether（稀薄气体） | `01` §3.5、`07` §3.0 |
| **「正/负」** | 磁荷极性／净电荷／电正负元素（**三种**） | `05` §1 |
| **「单质氢」** | 元素态 H₂／原子态 H·／氢原子内部两种 Anu 排列 | `joe cell/08` |
| **「两种氢」** | Anu 变体（OC）／ortho-para（主流）／氕氘氚（主流） | `joe cell/09` |
| **「E4」** | OC 的以太亚态 4／Phillips 的 omegon 层级 | `01` §7.1 |
| **「Occultum」** | 档案编为 1b（氢族 ⇒ ³H）／Smith 归为 ³He | `02` §4.3 |

**★★ 由此新增判据十三（详见 `07` §3.0）：**

> **判据十三：先别急着说两份资料「互相印证」或「互相矛盾」——
> 　　　　　先核对它们用的是不是同一个定义。**
> **检验方法：把两者的可检验属性（密度、组成、相态、量纲、单位）列成两列，逐格对照。
> 　　 任何一格冲突 ⇒ 不是同一个对象 ⇒ 该词不能作为连接两套体系的桥梁。**

**★ 三级核对顺序：**
```
① 对词  → 判据十三：同一个对象吗？
② 对量  → 判据④⑤：单位写全、换算到同一 SI
③ 对机制 → 判据⑥ ：数值对上了，机制是否同一
```

## 七、一句话结论（先把结论说了）

1. **OC 有一套内部自洽的数字体系**（Anu 数 ≈ 18 × 质量数），
   这套关系**真实存在**，不是随机巧合 —— 但它**不等于**现代原子量的解释。

2. **OC 完全没有核自旋概念**（ortho/para/自旋 全为 0 次），
   所以「OC 的两种氢 = ortho/para」**不是同一事实的两种说法**，
   而是**对象不同、属性不同**的两个命题。

3. **OC 说 H₂O 里两个 H 属于不同种类**；
   主流说 H₂O 的两个 H **全同**（正因如此分子整体才有 ortho/para）。
   **这两句方向相反** —— 是本系列最需要老师过目的地方。

4. **Phillips 的 6 倍靠理论、2 倍靠「重新解释观测数据」**
   （E. Lester Smith 原话，非编者推断）。这是**事后拟合**，不是预言。

5. **Lyne 与本系列无交集**（0 引用），他的 1,058 倍已在本项目 `11` 结案
   —— 错在 Van Nostrand 百科 1976 版 p.1311 的印刷，Lyne 逐字引用。

6. **旧解读的 `He = 54` 是硬错误**：原文 氦 = **72 Anu**，
   54 是 **Occultum**。旧的错误还有若干，见 `08`。

7. **Occultum = 氚（³H），不是 ³He**（老师指正，2026-09-12）。
   OC 自己把它编为 **1b（挂在氢之下）**，说它「位于氢和氦之间」，
   并在导论里明确写下「A=3 曾被当作氦，直到氦的 A 被宣布为 4，
   才意识到它是另一种气体」。⇒ **档案内部已亲手排除氦族归属。**
   （Anu 数 54 对 ³H 与 ³He 相同，**不构成判别依据**；
   　Smith 倾向 ³He 是拿「稳定同位素」这条**后设准则**倒推的结果。）

8. **★★ 「以太」是个口袋词，不能当连接两套体系的桥梁**（老师指正，2026-09-12）。
   它至少有三重所指：**科学界的以太 / OC 的 E1–E4 亚态 / koilon**；
   加上 Lyne 的 ether，**共四重**。
   其中 **koilon（绝对均匀坚固）与 Lyne 的 ether（不是固体而是气体）相态正好相反**。
   ⇒ **OC 自己就说过**：这假说「**在一个标题下包含了两组完全不同且相差甚远的现象**」，
   　 并自承把它叫以太「**也许是不明智的**」（原文第 125 行）。
   ★ 由此立 **判据十三（同名不同物）** —— 详见 §二 2.1。
