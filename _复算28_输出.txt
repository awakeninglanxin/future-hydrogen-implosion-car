============================================================================
Q0  先分清两种「锥角」（★ 这一步不做，后面全错）
============================================================================

  一个正圆锥有两个常用的「角」，二者**不是同一个量**：

      (A) 顶角 apex angle θ  ：两条母线在**顶点**处的夹角
      (B) 坡度角 slope angle φ：母线与**底面**的夹角

      几何关系：  φ = 90° − θ/2        （等价地：θ = 180° − 2φ）

        ┌────────────────────────────────────────────┐
        │            ▲  顶点                          │
        │           ╱ ╲                               │
        │          ╱ θ ╲   ← 顶角 (A)                 │
        │         ╱     ╲                             │
        │        ╱       ╲                            │
        │       ╱ φ     φ ╲  ← 坡度角 (B)             │
        │      ╱___________╲                          │
        └────────────────────────────────────────────┘

  ★ 两者差一个**非线性**换算 ⇒ 说「锥角 60°」时必须问是哪一个（判据⑬ 同名不同物）。


============================================================================
Q1  胡夫金字塔的角：三种表达
============================================================================

  公认尺寸（Cole 1925 测量）：
    原始底边 a = 230.33 m
    原始高度 h = 146.6 m

  ① **坡度角** φ = arctan(h / (a/2)) = arctan(146.6 / 115.165)
              = arctan(1.27296) = **51.848°**
              ≈ 51°50'52.0"  （即常说的 51°50'40"）
  ② **顶角** θ = 180° − 2φ = **76.304°**
  ③ **seked**（古埃及斜率单位）= 5.5 palms（每 1 cubit 升高）
              水平/垂直 = 5.5/7 = 0.7857 ⇒ 坡度角 = arctan(1/0.7857) = 51.843°  ✅ 与 ① 一致

  [OK] ★ 结论：**胡夫金字塔 坡度角 = 51.85°，顶角 = 76.30°**
  [!]  ⇒ 说「和胡夫一样」时，必须说清是哪一个！

  ★ 另外注意：**53° 附近**也常被引用 —— 那是**卡夫拉金字塔**（见 Q5），不是胡夫。

============================================================================

  --------------------------------------------------------
     60.00° |          60.00° | ★ 老师区间下界 / 库内区间下界（若按顶角）
     70.00° |          55.00° |

  --------------------------------------------------------
  [OK] ★ **顶角 60°–90° ⟺ 坡度角 90°−30°=60° 到 90°−45°=45°**

  ⇒ 注意这个换算的**方向**：顶角越大 ⇒ 锥越"扁" ⇒ 坡度角越小。
     · 顶角 60°（细高锥） ⇒ 坡度角 60°（陡）
     · 顶角 90°（宽扁锥） ⇒ 坡度角 45°

Q3  ★ 口径反推：库内那个「60°–90°」是哪种角？
============================================================================

  库内 03 L45：「锥角 60°–90°，316L 最优 57°；另说 52°–54° 更好」

  反推一：若「60°–90°」按**顶角**口径
     ⇒ 对应的坡度角 = 45° – 60°  = **45°–60°**
  [OK]     ★★ 与老师说的「45° 到 60°」**完全重合**！

  反推二：若「60°–90°」按**坡度角**口径
     ⇒ 对应顶角 = 180−2×90=0° – 180−2×60=60° ⇒ 0°–60°，无意义 ⇒ **不成立** ❌

  反推三：那「最优 57°」和「另说 52°–54°」呢？
     · 57° 若按**坡度角** ⇒ 顶角 = 180−2×57 = 66°（在 60–90 内 ✅）
     · 52°–54° 若按**坡度角** ⇒ 顶角 = 76°–72°
       ⇒ ★ 胡夫顶角 = 76.32°，**52° 那端几乎就是胡夫** ✅✅
     · 若把 57° / 52°–54° 当**顶角** ⇒ 坡度角 = 61.5° / 64°–63°，都超出 45–60
       ⇒ ❌ 不成立

  [!]  ★ 结论：**库内 L45 的数字里混用了两种口径** ——

     · 「60°–90°」  = **顶角**口径
     · 「57°」「52°–54°」 = **坡度角**口径
     ⇒ 这本身就是一个「同名不同物」的坑（判据⑬），本库此前未标注 ⇒ 现已补注。

Q4  ★★ 老师的「45°–60°」与库内「60°–90°」是不是同一组数？
============================================================================

  ┌──────────────┬────────────────────┬────────────────────┐
  │              │ 顶角 θ             │ 坡度角 φ            │
  ├──────────────┼────────────────────┼────────────────────┤
  │ 库内 03 L45  │ **60° – 90°**      │ （未写）            │
  │ 老师本轮     │ （未写）           │ **45° – 60°**      │
  └──────────────┴────────────────────┴────────────────────┘

  换算验证：
     顶角 60° ⇒ 坡度角 = 90 − 30 = **60°**  ✅
     顶角 90° ⇒ 坡度角 = 90 − 45 = **45°**  ✅

  [OK] ★★★ **两者数学等价**（只是口径不同）⇒ **不是矛盾，是同一组角度**

  ★ 并且它们**都涵盖胡夫金字塔**：
     · 胡夫顶角 = 76.30°  ⇒ 落在库内 60°–90° 内 ✅
     · 胡夫坡度角 = 51.85°  ⇒ 落在老师 45°–60° 内 ✅
