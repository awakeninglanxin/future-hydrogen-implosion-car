> 📌 **这张图最有价值的一点**：它提醒我们 **"氢氧内燃机比汽油机更早"**。

### 2.2 排除 H₂-ICE（p5–6）——这本书记录得相当扎实

作者引了三组硬数据说明"纯氢内燃机不行"：

| 案例 | 数据 | 问题 |
|---|---|---|
| **Ford P2000 H2ICE**（2001，改自 2.0L Zetec） | 效率比汽油机**高 25–30%** | 好，但只是实验室 |
| **Ford Tri-Flex 6.8L Triton V10**（2006） | 增压 18–20 psi → **235 hp@4000 / 310 lb-ft@3000** | 对比同款自然吸气汽油 V10：**305 hp@4250 / 410 lb-ft@3250** → **动力腰斩** |
| **BMW Hydrogen 7**（2007，约 100 辆） | 燃氢平均 **5.6 mpg ≈ 50 L/100km**；V12 氢机 **191.2 kW（256 hp）** vs 同机汽油 **438 hp** | 热效率 40–47%，低于燃料电池 60%（峰值） |
| **Ford + Daimler + Renault-Nissan 燃料电池联盟**（2013 宣布 / 2018-06 解散） | — | 作者以此说明"燃料电池路线自己都没走通" |

**作者给的关键机理（这是全书技术含量最高的一段）**：

```
H₂ + O₂ + N₂ → H₂O + NOx
降 NOx 的办法：用约 3 倍理论空气量（稀薄燃烧）
副作用：输出功率降到同样汽油机的约一半
→ 所以福特要加增压器，但输出仍偏低
```

> ✅ **编者判定**：这段是**正确的燃烧学**。氢的绝热火焰温度高（~2200 K in air）故易生成 NOx，
> 稀燃是业界公认真实手段，代价就是功率密度下降。**书在这里说的是业内共识，不是圈内说法。**

### 2.3 排除 FCV（p3、p7）

作者贴了三条新闻链接证明"燃料电池车退潮"（2013 三方合资 → 2018 解散），
并画了**氢能产业链老链条**，列出五个环节的问题：

| 环节 | 问题（书原文） |
|---|---|
| 制氢（裂解氨/甲醇、天然气转化、煤制、电解水） | High Cost Issue · Patent issue |
| 储运（高压 / 液氢 / 固态金属 / 有机液体） | **Hydrogen seepage**（氢渗漏）· Energy consumption & gas escape |
| 加注 | R&D in process |
| 应用（燃料电池：车/卫星/热电联产） | **Emision not free**（NOx 虽少但存在） |

→ 作者的结论：**"找对适合内燃机的氢燃料，才能正确打通汽车用氢产业"**（p43 原句）。

> 🟡 **编者判定**：**"氢储运难"是真的**（渗漏、氢脆、液化能耗都是真问题），
> 但作者的**归因是错的**：他拿"氢难储运"来论证"**HHO 好**"，

>
> **他真正想说的其实是 MHHO**——但他没在 1.0 里说清。这是全书**最大的含糊**。

## 三、板块 B："HHO 是什么"——6 条证据（p9–19）

### 3.1 前置：产生 HHO 的两个"必要条件"（p9）

> 1. 电极要**非常近**——**小于 1 mm 更好**
> 2. 要用**脉冲电解**设备

> 📌 **编者注**：极距小确实能**降低欧姆损耗、提高电流密度**（这是真实工程常识）；
> 脉冲电解也确有文献（脉冲能改善气泡脱离、降低过电位）。
> **但这两条只能"提高效率"，不能"改变产物"**——效率再高，产物还是按法拉第定律来。

### 3.2 六条证据逐条判定

| # | 书的证据（页） | 书想证明 | 编者判定 |
|---|---|---|---|
| **①** | **爆炸速度**：LPG `X` ＜ H₂+Air `3X` ＜ 2H₂+O₂ `12X` ＜ **HHO `18X`**（p11） | HHO 比 2H₂+O₂ 快 → 不是混合气 | 🟡 **方向对，但书内部矛盾**：p30 文字说"HHO 比 H₂ 快 3 倍、比汽油快 10 倍"，而表格算出的是 **6 倍、18 倍**。**表格与文字对不上** |

| **③** | **摩尔质量**：理论 (2/3 H₂+1/3 O₂) = **11.3** g/mol，Ohio 吸附实验室实测 **12.3** g/mol（p13） | 12.3 ≠ 11.3 → 不是混合气 | ❌ **书算错了**。`(2+2+32)/3 = 36/3 = **12.0**`（精确原子量 12.010）。实测 12.3 只偏 **+2.4%**，落在称重噪声内。**这条"头号证据"因算错基线而崩塌** |

### 5.3 编者独立复算

```
已知：1 m³ 化学计量 HHO 在 0 ℃ / 101.325 kPa 下 = 44.62 mol 气体
      其中 H₂ = 29.74 mol
      H₂ 高热值 HHV = 285.8 kJ/mol

含能 = 29.74 × 285.8 = 8,500 kJ = 2.361 kWh/m³

书宣称「100% = 2.36 kW」 → 复算 2.361  ✅ 完全吻合（且用的是 HHV 口径）

逐行回代：
  OKQYHJ 系列  3.0 kWh/m³  → 2.361 / 3.0 = 78.7%   书称 78.7%  ✅ 精确
  台湾 EP-350  2.7 kWh/m³  → 2.361 / 2.7 = 87.5%   书称 86%    ✅ 吻合
  台湾 EP-230  3.3 kWh/m³  → 2.361 / 3.3 = 71.6%   书称 72%    ✅ 吻合
  台湾 EP-500  4.2 kWh/m³  → 2.361 / 4.2 = 56.2%   书称 55%    ✅ 吻合
```

**另一个交叉校验**：

```
OKQYHJ 系列：3000 L/h ÷ 3.0 kW = 300 L/kWh
→ 反推槽电压 = 627 mL/Ah ÷ 300 L/kWh = 2.09 V/槽
→ 热中性电压 1.253 V ⇒ 效率 = 1.253 / 2.09 = 60%
（与 HHV 口径的 78.7% 差异，来自 HHV vs LHV 的口径不同——两者都对）
```

> ✅ **判定：这张表可信，而且是这批材料里质量最高的数据。**
>
> 它有三个优点：
> 1. **口径统一**（都用 HHV，所以"100% = 2.36 kWh/m³"能对上）；
> 2. **数量级合理**（60–88%，落在工业电解槽的常规区间）；
> 3. **没有出现超法拉第的奇迹**——最高 87.5%，仍在 100% 以下。
>
> 🔴 **最重要的意义**：
> **这张表恰好证明了"电解效率没有异常"。**
> 如果 HHO 真是"新物种"、真有"超常能量"，这里就该出现 >100% 的行——**但没有**。
> 作者把这张表放进来，本意是证明"HHO 已经成熟"，**无意中证明了"它很普通"。**

### 6.1 这张表暴露的三个逻辑漏洞

> **漏洞 1：HHO 与 MHHO 只差"纯度"，却从"不能烧"变成"能烧"**
> 同一来源、同一元素组成，只因"纯度更高"就：
> - 从"超 2 bar 爆炸"→"200 bar 安全"
> - 从"不能液化"→"可液化"
> - 从"极易燃、火花即着"→"不可燃、点不着"
>
> **这不是纯度的差别，这是物种的差别。** 但书没给任何机理说明这个转变怎么发生。

> **漏洞 2：一个"不可燃"的燃料**
> MHHO 被定为"理想燃料"，却又说"**常温下火花点不着**"。
> 那么内燃机里**怎么点火**？书靠"加压加热"（压燃）——但这意味着
> **MHHO 只能用于柴油机式的压燃机**，而书在 p47 却设计了汽油机式的多燃料柔性引擎。
> **两处自相矛盾。**

> **漏洞 3：p16 表格里直接写 "HHO/MHHO? -178°C"**
> 液化点这一栏，书**把 HHO 和 MHHO 写成了同一个值**。
> 但 p40 表说 HHO **不能液化**（氧会结晶）、MHHO **能液化**。
> **同一本书，两页相互打架。**

### 6.2 编者对这个漏洞的解释（这是本节的核心发现）

> ★ **真相很可能是：书里混用了两个不同来源的命名。**
>
> - **HHO** = Denny Klein（2002）/ Yull Brown 那条线 —— 实测的混合气
> - **MHHO** = Ryushin Omasa 大政隆心（2011，日本 Techno Co.）—— 后起的升级命名
>
> 作者**同时引用了这两条线**，但在写 p16/p40 时**没有把两者的物性分开**，
> 于是出现了"HHO 既是 HHO 又是 MHHO"的混乱。
>
> 📌 这与 `joe cell/07` 的发现**完全呼应**：
> `07` 指出 **"圈内对产物成分没有共识"**；这本书**自己在同一份文档内就演示了这个不共识**。

### 7.1 ★ 复算：352 MJ/kg 是什么概念

```
2H₂ + O₂ 混合气中，H₂ 的质量分数 = 4.032 / 36.030 = 11.19%

按混合气"总质量"算：
  LHV = 0.1119 × 120   = 13.4 MJ/kg
  HHV = 0.1119 × 141.9 = 15.9 MJ/kg

书写的 352 MJ/kg ÷ 15.9 = 22.2 倍

而且：
  352 MJ/kg > 纯氢 HHV 141.9 MJ/kg 的 2.48 倍
```

> ❌ **判定：这个数字在物理上不可能。**
>
> 一个**含有三分之二质量是氧化剂（O₂）的气体混合物**，
> 它单位质量的热值**必然只有纯燃料的三分之一左右**——
> 因为那 2/3 的氧**只贡献质量，不贡献能量**。
>
> 352 MJ/kg 甚至**超过了纯氢 2.48 倍**。这不是"性能好"，这是**热力学不可能**。
>
> **最可能的来源**：把某个**按氢质量**计的数值或笔误数字，直接填进了"按混合气质量"的栏里。
> 这与 `joe cell/07` §七 中发现的另一个同类错误（《独角兽 HHO》写"HHO 能量密度 140 MJ/kg"）
> **是同一种错误**——**混淆了"氢的热值"和"混合气的热值"**。

## 九、★ 编者复算：内爆真空到底能出多少功？

书的 HHO 3.0 主张链条是：

```
燃爆 → 瞬时生成水蒸气 → 冷凝 → 体积收缩 1:1859 → 负压真空
     → 大气压推水/推活塞 → "借大气压做功" → COP > 1
```

书的原话（p32）：
> "耗费 **1 度电**而产生的布朗气体，内爆后借助大气的压力**可以提升 340 公升的水**，
> 这比用电泵提取同样容量的水**省电几十倍**。"

### 9.1 算大气压能做的功上限

```
大气压对 340 L 体积可做的功 = P₀ × V
                            = 101,325 Pa × 0.34 m³
                            = 34,450 J ≈ 34.5 kJ

而制取这 1 kWh 的 HHO（即使 100% 效率）需投入：
                            3600 kJ

输出 / 输入 ≤ 34.5 / 3600 = 0.96%
```

> **即：大气压能做的功上限，只有投入能量的约 1%。缺口约 100 倍。**

### 9.2 与普通水泵对比

```
普通水泵效率按 30% 计，1 kWh 可提 340 kg 水的高度：
  h = (3600 × 0.30) / (340 × 9.81) = 324 m

而 HHO 内爆路线这 34.5 kJ 只够把 340 L 水推高约 10 m。
```

> ✅ **结论**：书里说"比电泵**省电几十倍**"——**方向完全反了**。
> HHO 内爆路线**比电泵费电约 100 倍**，不是省。
>
> 📌 **这与 `joe cell/07` §四 坑 3 的判定完全一致**：
> "借大气压做功**本身不违反**能量守恒（大气压确实在推），
> **但整条链的净额仍然是负的**——这两句话都对，且不矛盾。"
>
> **本节的贡献**：把"净额为负"从定性说法，**变成了具体倍数（约 100 倍）**。
