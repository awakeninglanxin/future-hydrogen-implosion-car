# 03 · HHO 到底是什么 —— 证据清单与逐条判定

> **本文定位**：把 `HHO1.0` 与 `HHO2.0` 两书的**全部关键主张**收进一张单子，
> **逐条复算、逐条标注证据强度**。这是三份精读里的**合订本**。
> 🔴 **凡本文给出的数字，都可以用计算器复核。**
> **配套**：`00`（总索引）、`01`（1.0 精读）、`02`（2.0 精读）、`joe cell/07`（三种氢之辨）

## 〇、先把问题问对

"**HHO 到底是什么？**"这个问题，一旦问出口，就必须先明确**在哪一层回答**：

| 层 | 问题 | 答案 |
|---|---|---|
| **命名层** | "HHO"这个词指什么？ | 一个**定义不清的商品名**（书 p18 自己也这么说） |
| **物质层** | 电解产出的东西**有没有新物种**？ | **没有**。是 H₂ + O₂ + 水蒸气 + 微量杂质 |
| **能量层** | 它**能不能净产能**？ | **不能**。制取耗能 > 燃烧放能（热力学第二定律） |
| **工程层** | 它**有没有用**？ | ✅ **有**。掺氢改善燃烧、切割、焊接、除碳——**都真实有效** |

> ★ **四个问题，四个不同的答案。所有"HHO 之争"的混乱，都来自把四层混成一层。**
>
> - 说"HHO 有用"→ 问的是**工程层**，✅ 成立；
> - 说"HHO 是新物质"→ 问的是**物质层**，❌ 不成立；
> - 说"HHO 能产能"→ 问的是**能量层**，❌ 不成立。
>
> **这三句话可以同时为真**——因为它们说的是**不同的层**。

### 复算 ① 摩尔质量：书把 12.0 写成了 11.3

**书原文（2.0 p13 / 1.0 p13）**：

> "2/3 H2 + 1/3 O2 =(2 + 2 + 32)/3 = **11.3**g/mol.
> On June 30, 2003, Adsorption Research Laboratory of Dublin, Ohi, measured the specific
> weight of the HHO gas and released a signed statement on the resulting value of **12.3** g/mol…
> The released value of 12.3 g/mol is **anomalous**."

**编者复算**：

```
书自己写的算式：(2 + 2 + 32)/3
                 = 36 / 3
                 = 12.0          ← 不是 11.3

用精确原子量：2/3 × 2.016 + 1/3 × 31.998
             = 1.344 + 10.666
             = 12.010 g/mol

⇒ 理论值 12.010，实测 12.3
⇒ 偏差 = (12.3 − 12.010) / 12.010 = +2.4%
```

> ❌ **判定：这条证据因算错基线而崩塌。**
>
> - 书想证明的是：**实测 12.3 ≠ 理论 11.3**，所以"不是混合气"；
> - 但**理论值是 12.0**，实测 12.3 只偏 **2.4%**；
> - **2.4% 落在气体称重法的正常误差内**（温度、压力、水蒸气夹带、湿度都会造成 2–3% 偏差）。
>
> 🔴 **这是全部六处复算里最要紧的一处**——
> 因为它是"**HHO 不是 2H₂+O₂**"这条主线的**唯一强证据**。
> 其他五条（爆炸速度、火焰温度、IR 谱、SwRI 结构、液化点）**都能用常规物理解释**（见 §二）。
>
> **唯一的强证据算错了 → 整条主线失去支点。**

### 复算 ② L-MHHO 的密度：书给了两个互不自洽的数

**书给的数据**：

| 出处 | 数值 |
|---|---|
| 1.0 p17 / p42（图示） | **517.2 kg/m³**（标注 "2/3 LH₂ + 1/3 LO₂ = 517.2 kg/m³"） |
| 1.0 p42（另一处） | **1503 kg/m³**（标注 "Liquid MHHO Density"） |
| 1.0 p17 | **167 kg/m³**（"converted to Hydrogen content"） |

**编者复算（两种口径）**：

```
【口径 A：按体积配比，2/3 体积液氢 + 1/3 体积液氧，取 1 m³】
   ρ(LH₂) = 70.8 kg/m³，ρ(LO₂) = 1141 kg/m³
   质量 = 2/3 × 70.8 + 1/3 × 1141 = 47.2 + 380.3 = 427.5 kg
   ⇒ 密度 ≈ 427.5 kg/m³

【口径 B：按化学计量，2 mol H₂ + 1 mol O₂ 的液体体积】
   2 mol H₂ = 4.032 g，液体积 = 4.032/70.8 = 0.05694 L = 56.9 mL
   1 mol O₂ = 31.998 g，液体积 = 31.998/1141 = 0.02804 L = 28.0 mL
   合计体积 = 84.98 mL，总质量 = 36.030 g
   ⇒ 密度 = 36.030 / 84.98 × 1000 = 423.9 kg/m³

两种口径一致：≈ 425 kg/m³
```

| 书的值 | 与复算值（425）比 | 判定 |
|---|---|---|
| **517.2** | +22% | ❌ 来源不明 |
| **1503** | **+254%** | ❌ **比液氧（1141）还高 32%；比水（1000）高 50%** |

> ❌ **判定：两个数字互不自洽，且第二个物理上讲不通。**
>
> **最致命的一点**：书主张 MHHO 是"**水的同分异构体**"。
> **同分异构体的密度应当约等于水的密度（1000 kg/m³）**，
> 而书给的是 **1503**——**比水还重 50%**。**这直接推翻了自己的核心主张。**

### 复算 ③ "MHHO 含氢量是液氢的 2.4 倍"—— 这句话反而证伪了新物种

**书的论述（1.0 p42 / p17）**：

> "Hydrogen Density：L-H₂ **70.8** kg/m³ ；L-MHHO **167** kg/m³
> **A cubic meter of MHHO contains 2.4 times more hydrogen by mass (167 kg),
> than a cubic meter of liquid hydrogen (70kg).**"

**编者复算**：

```
✅ 算术部分对：167 / 70.8 = 2.36 ≈ 2.4 倍

但这个 2.4 倍说明了什么？
  167 / 1503 = 11.11%   ← L-MHHO 中氢的质量分数

  而水的氢质量分数 = 2 / 18.015 = 11.10%

  ⇒ 两者几乎完全相同！
  ⇒ 任何"密度接近水"的液体（H:O = 2:1），天然就含 ~110 kg-H/m³
  ⇒ 这已经是液氢（70.8）的 1.57 倍
```

> ★ **判定：这个"2.4 倍"不是新物种的证据，而是"水含氢 11%"的换名说法。**
>
> **逻辑链条**：
> 1. HHO/MHHO 的 H:O 比 = 2:1（**与水的组成相同**，这是书自己反复强调的）；
> 2. 所以**只要它密度接近水，含氢量就必然接近 110 kg/m³**；
> 3. **而液氢只有 70.8 kg/m³**——因为液氢是**纯氢**，密度极低（70.8）；
> 4. **所以"含氢比液氢多"是必然的，与"是不是新物种"无关。**
>
> 🔴 **更深一层的问题**：这些氢**已经与氧成键（就是水）**。
> **不解除化学键，这些氢一点都用不了；而解除键（电解）要付电费。**
> 所以"含氢多"这个指标**在能量上完全无意义**。

### 复算 ④ SCP 案例：书说"省电几十倍"，实为"费电约 100 倍"

**书原文（2.0 p32）**：

> "据 SCP 公司的计算，**耗费 1 度电**而产生的布朗气体，内爆后借助大气的压力
> **可以提升 340 公升的水**，这比用电泵提取同样容量的水**省电几十倍**。"

**编者复算**：

```
【大气压能做的功上限】
   W = P₀ × V = 101,325 Pa × 0.34 m³ = 34,450 J ≈ 34.5 kJ

【投入】
   制取这 1 kWh 的 HHO，即使按 100% 效率，需投入
   = 1 kWh = 3,600 kJ

【比值】
   输出 / 输入 ≤ 34.5 / 3600 = 0.96%
   ⇒ 缺口约 100 倍

【对照真实水泵】
   普通水泵效率按 30%：
   h = (3600 kJ × 0.30) / (340 kg × 9.81 m/s²) = 1080/3.335 = 324 m
   ⇒ 同一度电，普通水泵能把 340 L 水推高 324 m
   ⇒ HHO 内爆路线只能推高约 10 m
```

> ❌ **判定：书的"省电几十倍"，方向完全反了——实际是"费电约 100 倍"。**
>
> **书哪里算错了？**
> 它把"**大气压推水**"记在了**收入栏**，却把"**制取 HHO + 冷凝造真空**"漏在**支出栏外**。
>
> **严谨的说法（两句话都对，且不矛盾）**：
> 1. ✅ "借助大气压做功**没有违反**能量守恒"——**对**，大气压确实在推；
> 2. ❌ "所以整条链能净赚"——**错**，因为**制造真空要花掉比它更多的能量**。

### 复算 ⑤ ★ 电解槽效率表：完全自洽（这是唯一通过核验的硬数据）

**书的数据（1.0 p38）**：

| 型号 | 能耗 kWh/m³ | 书称效率 |
|---|---|---|
| （基准） | — | 书标 "100% = **2.36 kW**" |
| 中国 OKQYHJ 全系列 | **3.0** | **78.7%** |
| 台湾 EP-350 / EP-350B+ | 2.7 | 86% |
| 台湾 EP-230 / EP-230C | 3.3 | 72% |
| 台湾 EP-500 | 4.2 | 55% |

**编者复算（HHV 口径）**：

```
1 m³ 化学计量 HHO @0 ℃ = 1000 / 22.4136 = 44.62 mol 气体
其中 H₂ = 44.62 × 2/3 = 29.74 mol
H₂ 高热值 HHV = 285.8 kJ/mol

含能 = 29.74 × 285.8 = 8,500 kJ = 2.361 kWh/m³
     ⇒ 书宣称的"100% = 2.36"  ✅ 完全吻合

逐行回代：
   OKQYHJ 3.0 → 2.361/3.0 = 78.7%    书称 78.7%   ✅ 精确
   EP-350 2.7 → 2.361/2.7 = 87.5%    书称 86%     ✅ 吻合
   EP-230 3.3 → 2.361/3.3 = 71.6%    书称 72%     ✅ 吻合
   EP-500 4.2 → 2.361/4.2 = 56.2%    书称 55%     ✅ 吻合
```

**交叉校验**：

```
OKQYHJ：3000 L/h ÷ 3.0 kW = 300 L/kWh
反推槽电压 = 627 mL/Ah ÷ 300 L/kWh = 2.09 V/槽
热中性电压 = 1.253 V
⇒ 效率 = 1.253 / 2.09 = 60%（LHV 口径，与 HHV 口径的 78.7% 差异来自口径不同，两者都对）
```

> ✅ **判定：这张表可信，是全部材料里质量最高的数据。**
>
> **它有三个优点**：口径统一（HHV）、数量级合理（56–88% 落在工业电解槽常规区间）、**没有超法拉第的奇迹**。
>
> ★ **最有意味的一点**：
> **这张表恰好证明了"电解效率没有异常"。**
> 如果 HHO 真是"新物种"、真有"超常能量"，**这里就该出现 >100% 的行——但没有**。
> 作者放这张表是想证明"HHO 技术成熟"，**无意中证明了"它很普通"**。

### 复算 ⑥ HHO 混合气的真实热值：书写的 352 MJ/kg 是它的 22 倍

**书的表（1.0 p44）**：

| 指标 | 汽油 | H₂-ICE | **HHO-ICE** | HFC |
|---|---|---|---|---|
| 热值 MJ/kg | 44.0 | 141.9 | **352\*** | 141.9 |
| 系统效率 % | 20–40 | 40–47 | **50–80\*** | 50–80\* |

**编者复算**：

```
2H₂ + O₂ 中，H₂ 的质量分数 = 2 × 2.016 / (2 × 2.016 + 31.998)
                            = 4.032 / 36.030
                            = 11.19%

按"混合气总质量"算热值：
   LHV = 0.1119 × 120.0 = 13.4 MJ/kg
   HHV = 0.1119 × 141.9 = 15.9 MJ/kg

书写的 352 ÷ 15.9 = 22.2 倍

更直接的荒谬性：
   352 MJ/kg > 纯氢 HHV（141.9）的 2.48 倍
   —— 一个混合物，单位质量热值超过其纯组分 2.5 倍，热力学不可能
```

| 燃料 | 热值 MJ/kg |
|---|---|
| 汽油 | 44.0 |
| 柴油 | 42.7 |
| 甲烷 | 55.5 |
| **纯氢（HHV）** | **141.9** |
| **2H₂+O₂ 混合气（HHV，实算）** | **15.9** |
| **2H₂+O₂ 混合气（LHV，实算）** | **13.4** |
| ~~书的 "HHO"~~ | ~~352~~ ❌ |

> ❌ **判定：这个数字在物理上不可能。**
>
> **根本原因**：混合气里**三分之二的质量是氧化剂（O₂）**。
> **氧化剂只贡献质量，不贡献能量。**
> 所以混合气的单位质量热值，**必然只有纯燃料的三分之一左右**（11.19% × 141.9 = 15.9）。
>
> 📌 **同类错误的第二次出现**：
> `joe cell/07` §七 已记录过另一处同类错误——
> 《独角兽 HHO》写"**HHO 能量密度 140 MJ/kg**"，而 140 正是**氢的 HHV**。
> **两批独立材料，犯的是同一个错误：把"氢的热值"当成"混合气的热值"。**

### 2.1 六条证据的结构性缺陷

> ★ **编者补充：这六条证据有一个共同的结构问题——**
>
> | 类型 | 证据 | 问题 |
> |---|---|---|
> | **算错的** | ③ 摩尔质量 | 基线 12.0 写成 11.3 |

>
> **六条里，没有一条经得起独立复核。**
> 而这六条，就是"**HHO 是新物种**"的全部论证。

## 三、"内爆"的正确定性

这是全部争议里**最容易被误解**的一点。**分四句话说清**：

| # | 说法 | 判定 |
|---|---|---|
| 1 | 电解产气：液态水 → 气体，**体积膨胀约 1,860 倍** | ✅ **真**（0 ℃ 下 1 kg 水 → 1,866 L 气体） |
| 2 | 燃烧 + 冷凝：气体 → 液态水，**体积收缩约 1,860 倍** | ✅ **真**（蒸汽冷凝是真实的物理相变） |
| 3 | 因此能形成**真空负压** | ✅ **真**（密封容器内蒸汽冷凝确实造真空） |
| 4 | 因此能"**借大气压做功、实现 COP>1**" | ❌ **伪**（漏算了制真空的成本；复算缺口约 100 倍，见复算 ④） |

### 3.1 为什么第 4 条不成立—— 一句话版本

> **真空不是白来的。**
>
> ```
> 真空 ← 来自蒸汽冷凝
>      ← 冷凝需要降温（潜热释放）
>      ← 热量来自燃烧
>      ← 燃烧的氢来自电解
>      ← 电解的电来自你付的那 1 度电
>
> 你想收的是"大气压推水"这笔收入；
> 但你要付的是"制取 HHO + 冷凝成真空"这两笔支出。
> 支出 > 收入，缺口约 100 倍。
> ```

### 3.2 书里那句话，为什么"一半对一半错"

书的原话：

> "因为用布朗气体内爆后造成的真空抽水**是借助了大气的压力**，
> 所以以上的设想**并没有违反能量守恒定律**。"

| 部分 | 判定 |
|---|---|
| "借助大气压做功" → 没违反守恒 | ✅ **完全正确**。大气压确实在推，这部分功确实来自大气 |
| "所以整条设想成立" | ❌ **错误推论**。因为**造真空要花费更多** |

> ★ **这两句话不矛盾**——**"不违反守恒"和"净额为负"可以同时为真。**
> 正如：**用 1 度电把水抽上去再放下来发电，也不违反能量守恒，但一定亏**。

### 3.3 与本项目 `07` 的呼应

| `joe cell/07` §四 坑 3 的说法 | 本文的补充 |
|---|---|
| "内爆是 H₂+O₂ → H₂O 相变的体积收缩（气→液）" | ✅ 一致（本文 §三 第 2 条） |

## 六、★ 一个反转：书的"缺点清单"恰恰证明了它是混合气

这是本文**最有意思的一个发现**。

**书 1.0 p40 列出了 HHO 的这些"缺点"**：

| 书的原文 | 编者读法 |
|---|---|
| `CANNOT be compressed over 2 bar - **explodes**`（超 2 bar 爆炸） | ✅ **这是富氢混合气的正常性质** |
| `CANNOT be stored in bottles`（不能装瓶） | ✅ 同上 |
| `Significant Hydrogen **LEAKAGE** observed through regular sealants`（普通密封件明显渗漏） | ✅ **氢分子极小，这是氢的固有性质** |
| `EXTREMELY **FLAMMABLE** - CAN be ignited by a small spark`（极易燃，小火花即着） | ✅ **H₂/O₂ 混合气最小点火能约 20 μJ**（NASA 手册），**这是标准值** |
| `CANNOT be liquefied - **oxygen crystallizes**`（不能液化，氧会结晶） | ✅ **氧在 -218 ℃ 结晶，而 N₂ 是 -210 ℃**——这是**真实的分馏难题** |

> ★★ **编者补充：作者把这张清单叫"缺点"，但它其实是"物质鉴定书"。**
>
> 请对照 **2H₂+O₂ 混合气的标准性质**：
>
> | 性质 | 2H₂+O₂ 的标准值 | 书里说的 HHO |
> |---|---|---|
> | 可燃范围 | 4%–95% H₂（极宽） | "极易燃、小火花即着" ✅ |
> | 最小点火能 | ≈20 μJ | 与上一致 ✅ |
> | 自燃温度 | ≈570 ℃ | "超 2 bar 爆炸"（加压升温自燃） ✅ |
> | 氢渗漏 | **氢分子极小，是储运主难题** | "普通密封件明显渗漏" ✅ |
> | 不能液化 | **氧先结晶，无法分馏** | "氧会结晶" ✅ |
>
> **五项全部吻合。**
>
> 🔴 **换句话说：书列出的"HHO 的五大缺点"，恰好逐项证明了"它就是 2H₂+O₂ 混合气"。**
>
> **这不是巧合**——因为**这些"缺点"本来就是"氢氧混合气"这个物种的标准性质**。
> 一个真正的新物种，**不会有如此标准地吻合的物性表**。

### 6.1 那"MHHO 可加压 200 bar、无渗漏、不可燃"怎么解释？

这是唯一"不吻合"的一档。**三种可能**：

| 可能 | 说明 |
|---|---|
| **(a) 数据错误** | 抄录/转述出错（书内已多处自相矛盾，可能性最大） |
| **(b) 就是高压下的混合气** | 200 bar 下氢氧混合气**不会自动爆炸**（需点火源），"无渗漏"可能是**容器材质更换**（如金属内衬），"不可燃"可能是**缺氧配比** |
| **(c) 真新物种** | **需要第三方复现**——至今没有 |

> **在拿到第三方数据前，(a)/(b)/(c) 无法区分。**
> **但注意**：如果是 (b)，那 MHHO **仍然是混合气**，只是工艺条件不同——
> 这与书 p8 作者自己说的"**成分随工艺变化、比例不恒定**"**完全吻合**。

## 七、四张账：把"能量"这件事算到底

对比要成立，必须在**同一基准**上。这里给出四张账（每张都能用计算器复核）：

### 账 ① 电解侧：制 1 m³ HHO 的最低能耗

```
理论最小（HHV 基准，25 ℃ 液态水）= 2.36 kWh/m³
理论最小（LHV / 热中性基准）    = 2.00 kWh/m³
工业实际                         = 2.7 – 4.2 kWh/m³（复算 ⑤，效率 56–88%）
```

### 账 ② 燃烧侧：烧 1 m³ HHO 能拿回多少

```
1 m³ HHO 含 H₂ 29.74 mol
燃烧放热 = 29.74 × 241.8 kJ/mol（LHV）= 7,192 kJ = 2.00 kWh
（若按 HHV 计 = 2.36 kWh）
```

> **账①②对比**：**放回 2.00–2.36 kWh，投入 2.7–4.2 kWh。**
> **⇒ 缺口 35–80%。这就是"为什么车载电解不划算"的全部算术。**

### 账 ③ 车载侧：1 A 电解 vs 车辆需求

```
1 A 电解产氢：6.96 mL/min（★ 报告已复算）
车辆 15 kW 巡航需 H₂：
   15,000 W ÷ 120 MJ/kg = 0.125 g/s
   = 0.062 mol/s × 22.414 L/mol × 60 = 83.4 L/min
缺口 = 83.4 / 0.00696 = 约 12,000 倍（≈ 10⁴）
```

> 这正是 ★ 报告摘要说的"**约 10⁴ 倍缺口**"（与 §3.2 表格的 2,600 倍不一致，见 `joe cell/06` §二）。

### 账 ④ 内爆侧：大气压能做的功上限

```
340 L 水被大气压推：W = P₀V = 101,325 × 0.34 = 34.5 kJ
投入 1 kWh = 3,600 kJ
⇒ 输出/输入 ≤ 0.96%
```

> ★ **四张账合起来一句话**：
> **电解亏（② < ①）、车载亏（③）、内爆亏（④）。
> 三条路各自独立地亏，且亏的方式不同——
> 所以"把它们串起来"不会互相补偿，只会累加亏损。**
