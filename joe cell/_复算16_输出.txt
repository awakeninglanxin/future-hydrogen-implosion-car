
==========================================================================
① 术语层级归位：两套语言说的不是同一层的东西
==========================================================================

  「变体 1 / 变体 2」（微灵视档案，08 / 09）：
      · 说的是【一个氢原子内部】的 Anu 排列方式
      · 层级：亚原子层（原子核内部构想）
      · 判别量：正 / 负 Anu 的个数（9/9 或 10/8）—— 是【旋向计数】
      · 证据等级：🟡 圈内档案（不可重复验证）

  「ortho / para」（主流物理，1929 预言 / 1932 确认）：
      · 说的是【一个分子内两个氢核】核自旋的相对取向
      · 层级：分子层（两核之间的关系量）
      · 判别量：两核自旋平行（I=1）还是反平行（I=0）
      · 证据等级：✅ 光谱 / 热容 / 中子散射 / 太赫兹光谱反复实测

  → 两者【层级不同】，但这不构成「谁对谁错」；
    真正要检验的是：**「两核是否属于两种不同的内部结构」能不能承担
    「两核自旋的平行 / 反平行」这个角色**。
    下面逐项做。

  ★ 一个先决问题：「×2」有三种可能读法，本脚本按读法 C 为主检验

     读法 A：「两个变体 1 拼成一个 H₂」   → 该 H₂ 由两个变体 1 组成
     读法 B：「变体 1 内部本来就有一对」   → 强调结构里的成对性
     读法 C：「两种配对方式分别对应两种氢分子形态」（ortho / para）← 本脚本主检验

  ⚠️ 与既有结论的冲突检查（重要）：
     · 08 / 09 的结论是：H₂ 里是「**变体 1 + 变体 2 各一个**」
     · 假设说：ortho 那一种是「**变体 1 + 变体 1**」
     → 读法 A 与 08/09 的结论**直接冲突**（同一种分子，一个说各一、一个说同款）
     → 读法 C 不与 08/09 冲突（08/09 讲的是「配对成分」，「ortho/para」讲的是「配对方式」）
        —— 所以读法 C 才是可以认真检验的版本

② 核自旋四态穷举：3 个 ortho + 1 个 para
==========================================================================

  两个质子，每个自旋 1/2 → 各有 α(↑) / β(↓) 两态 → 共 4 个乘积态：

    |态>                     拼写              交换两核后      对称性
    ────────────────────────────────────────────────────────────────────
    |α₁α₂>   = |↑↑>                        交换后仍 |↑↑>      对称
    |β₁β₂>   = |↓↓>                        交换后仍 |↓↓>      对称
    |αβ+βα>/√2             (↑↓ + ↓↑)       交换后不变        对称
    |αβ−βα>/√2             (↑↓ − ↓↑)       交换后 → 负号     反对称
    ────────────────────────────────────────────────────────────────────
      对称 3 个 → I = 1 三重态 → **ortho**    （m_I = +1, 0, −1）
      反对称 1 个 → I = 0 单态 → **para**

  逐项列出：
    |↑↑>           对称     → ortho  (m_I = +1)
    |↓↓>           对称     → ortho  (m_I = −1)
    (↑↓+↓↑)/√2     对称     → ortho  (m_I = 0)
    (↑↓−↓↑)/√2     反对称    → para   (I = 0)

  → ortho 态数 = 3 ／ para 态数 = 1
  → 高温极限（四个态等概率）ortho : para = 3 : 1 = 3 : 1

  ★★ 这就是「3 : 1」的**全部来源** —— 它是【数态数数出来的】，不需要任何能量输入。
     在 T → ∞ 的极限下，只要有 4 个自旋态、其中 3 个属 ortho，比例就必然是 3:1。

  ★ 顺带回答假设里的「对称 / 反对称」直觉：
     「两个同款（对称）+ 两个异款（反对称）」——**这个结构在核自旋层面是真的**，
     但 4 个组合里 3 个属 ortho、只有 1 个属 para，
     所以它给出的是 **3:1**，不是 **1:1**。

③ H₂ 的 3:1 与温度依赖（Boltzmann 独立复算）
==========================================================================
  转动常数 B_e(H₂)        = 60.853 cm⁻¹   （NIST CCCBDB / Huber & Herzberg 1979）
  特征转动温度 θ_r = B/k  = 60.853 × 1.4387769 = 87.55 K

  温度      para 分数     ortho 分数    ortho : para
  --------------------------------------------------------
    20.3 K     99.839 %      0.161 %       0.00 : 1
    40.0 K     89.848 %     10.152 %       0.11 : 1
    77.0 K     52.056 %     47.944 %       0.92 : 1
   150.0 K     28.983 %     71.017 %       2.45 : 1
   273.1 K     25.163 %     74.837 %       2.97 : 1
   298.1 K     25.084 %     74.916 %       2.99 : 1
   400.0 K     25.006 %     74.994 %       3.00 : 1
   500.0 K     25.000 %     75.000 %       3.00 : 1

  文献对照（外网核实 ✅）：
    · 20.3 K（液氢沸点）→ para ≈ 99.86 %     ✅ 本算 99.8x %
    · 273 K / 室温      → para ≈ 25 %（即 3:1）✅ 本算与之一致

④ ★ 核心判据：ortho/para 存在的必要条件是「两个核完全全同」
==========================================================================

  这是本轮最硬的一条，也是**唯一一条能直接判否假设**的判据。逻辑只有两步：

  第一步：为什么 H₂O 也有 ortho/para？
      H₂O 里的两个 H 是【全同的质子】→ 交换两个 H 时波函数必须满足对称性要求
      → 由此才划出「核自旋对称（3 个态）／反对称（1 个态）」两类
      → 这就是 H₂O 的 ortho / para（水蒸气实测 3:1，太赫兹光谱已确认）

  第二步：如果把其中一个 H 换掉（H → D），会怎样？
      **HDO（半重水）的两个核一个是质子、一个是氘核，不再全同**
      → 交换对称性要求**不存在**
      → **HDO 没有 ortho/para 之分**


--------------------------------------------------------------------------
外网核实（两处独立来源，措辞一致 ✅）
--------------------------------------------------------------------------
  · RSC, Faraday Discussions 2024（HDO–Ne/H₂ 散射研究）:
      "For HDO, this ortho/para modification does not apply
       and all HDO levels are collisionally connected."
  · water-science（Martin Chaplin 站，正交引用）:
      "HDO, having non-equivalent hydrogen atoms,
       does not possess an ortho:para distinction."


--------------------------------------------------------------------------
★ 反过来用这条判据
--------------------------------------------------------------------------

  假设的核心是：**H₂O 里那两个 H，一个是变体 1、一个是变体 2 —— 两者不相同。**
  那么按同一条逻辑：

      两个 H 若真的【不相同】
            ↓
      交换对称性要求不成立
            ↓
      H₂O 就【不该】有 ortho / para
            ↓
      但 H₂O 的 ortho / para 被反复实测到了
         （太赫兹光谱 0–3 THz 振动能级 / 四波混频 / NMR / 朗缪尔吸附分离）
            ↓
      ★ 结论：**「H₂O 里两个 H 不相同」与「H₂O 有 ortho/para」不能同时成立**

  ⚠️ 注意判定的**力度级别** —— 这里要诚实：
     · 这不是「数字对不上」（那种可以争论）
     · 这是【两项之间互相排斥】：假设成立 → 一项被实测的事实消失
     · 但若把「变体」解释成**不可观测的内部标签**（对交换对称性无影响），
       则逻辑上可以绕过 —— 代价是：**这个假设从此不产生任何可检验的预言**


==========================================================================
⑤ 比例检验：配对方式给出的比例，对不上
==========================================================================

  假设给出两种配对：
      配对 I = 变体1 + 变体1   →  对应 ortho
      配对 II = 变体1 + 变体2  →  对应 para

  两种配对的**先验概率**：材料没有给出任何机制说明「哪一种更常见」，
  最自然的默认是**等概率**（各 1/2）→ 给出 **1 : 1**。

  但实测比例是：
    H₂ 气体（室温平衡）          3 : 1     由 4 个核自旋态数出来的统计权重                  ✅ 实测
    水蒸气                  3 : 1     同上（太赫兹光谱 0–3 THz 确认）               ✅ 实测
    液态水                  ≈ 1 : 1   氢键影响，偏离统计权重、且远离平衡                  ✅ 实测（且有争议范围）
    ★ 假设（配对 I : 配对 II）   1 : 1     两种配对等概率 → 但 H₂ 实测不是 1:1            ❌ 与 H₂ 实测不符

  → 若要把 H₂ 的 3:1 解释成「配对 I 比配对 II 常见 3 倍」，需要**额外机制**。
    假设本身没有提供这个机制，所以这一项是**未配套**（不是被证否，是缺件）。

  ★ 这里有个值得留心的现象：**「1 : 1」在两处出现，但来路不同。**
      · 假设给出的 1:1  = 两种配对的等概率（对 H₂ 是错的）
      · 液态水实测的 1:1 = 氢键导致 ortho/para 偏离 3:1（对水是对的）
    下一节专门处理这两条「1:1」的关系。


==========================================================================
⑥ ★★ 两条「1 : 1」是否同源？（本轮最深的一层）
==========================================================================

  把两条线索并排：

     线索甲（圈内档案 · 09 笔记，1932 年观察）：
         「在 H₂O 分子中，一个氢原子属于第一种变体，另一个属于第二种变体。」
         → 若每个水分子都如此，宏观上「两种变体 ≈ 1 : 1」

     线索乙（主流物理 · 液态水）：
         液态水的 ortho : para ≈ **1 : 1**（水蒸气才是 3:1）
         原因：氢键使体系远离统计权重给出的平衡值
         来源：Springer 2024、water-science、arXiv 2210.16149 一致记载 ✅

  ★★ 两条「1:1」说的**可能是同一件事** ——
      微灵视在 1932 年"看到"的「两个 H 不一样」，很可能**就是** ortho/para 本身：
      · 他们观察到的是**真实存在的效应**（液态水里 ortho:para 确实偏离 3:1、接近 1:1）
      · 但把它**解释成「两种不同的原子」**，而实际是**同一原子的两种自旋取向**

  → 这比 09 §4.2 写的「数字巧合」更精确。准确的说法是：
      **不是巧合，而是「同一事实、两种解读」** ——
      他们看到的对象是对的，**错的只是层级归属**（把分子层的自旋关系读成了亚原子层的结构差异）。

  ⚠️ 但仍存一个未解项，必须标出来：

     · 他们说的是 **H₂O**（水）里的两个 H
     · 液态水的 1:1 是**宏观系综**的比例（无数水分子，各分子本身仍是 3:1 的态分布）
     · 一个水分子内部「这两核自旋平行还是反平行」**本身就是 ortho/para 的定义**
     → 所以「每分子各一」与「系综 1:1」**不是同一句话**：
         前者若指「每个分子都反对称（para）」→ 那应是 **100 % para**，不是 1:1
         只有当它指「系综里两类分子各半」→ 才等于 1:1
     → 档案原文太简略，**无法确定它指的是哪一个** ⚪ 存疑

⑦ ★ D₂O 对照组：一个能一举定性的查证方向
==========================================================================

  如果「两条 1:1 同源」成立（即微灵视看到的 = ortho/para），
  那么把它套到**重水 D₂O** 上，应该看到什么？

  D₂O 的核自旋异构（外网核实 ✅）：
     · 氘核（deuteron）自旋 I = 1，是**玻色子**（H 的质子是费米子）
     · 玻色子 → 对称性要求**反过来**：ortho 对应**偶数** J、para 对应**奇数** J
     · 基态（J=0）是 **ortho**（H₂ 里基态是 para —— 完全相反）
     · 室温 ortho : para = **2 : 1**（不是 3:1，也不是 1:1）
     · ortho 与 para 最低能级差 12.117 cm⁻¹（D₂¹⁶O）

  → 于是得到一条**可判定的定性预言**：

      若档案里对 **D₂O** 的记录仍是「两个 D 一个属变体 1、一个属变体 2」（1:1），
          → 说明他们的「两种变体」**不是** ortho/para（因为 D₂O 应为 2:1）

      若档案里对 D₂O 的记录变成「2:1」（或指出与 H₂O 不同），
          → 那就**强烈支持**「他们看到的就是 ortho/para」

  ★★ 这是一条**能一举定性的查证方向** —— 不需要新实验，
     只需在微灵视档案（OC 及其附录）里**检索有没有重水 / 氘的观察记录**，
     看它给的配比是 1:1 还是 2:1。

  当前状态：
     · 手上材料（08 / 09 / 10 三份笔记）**未见 D₂O 的记录**
     · 氘的线索只有 09 §1.2 那条：「两个氢组成的团质量是普通氢的两倍，正如氘所要求的」
       —— 那条说的是**氘核**（²H），不是**重水分子**（D₂O），**不能当证据用**
     · 判定：⚪ 待查（列入 `06_编者校核与后续清单.md`）

⑧ 能量差复算（两项，用于交叉校验前面用到的常数）
==========================================================================

--------------------------------------------------------------------------
(a) H₂：ortho 基态(J=1) 与 para 基态(J=0) 之差
--------------------------------------------------------------------------
  B_e           = 60.853 cm⁻¹
  E(J=1) − E(J=0) = 2B_e = 121.706 cm⁻¹
  → 换算          = 121.706 × 11.9627 = 1455.9 J/mol = 1.456 kJ/mol
  → 折合温度      = 121.706 × 1.4387769 = 175.1 K
  文献：1.455 kJ/mol ／ 15.1 meV ／ 175 K（Wikipedia / arXiv 2210.16149）
  ★ 偏差：0.06 %  ✅ 一致

--------------------------------------------------------------------------
(b) H₂O：para 基态 |0₀₀> 与 ortho 基态 |1₀₁> 之差
--------------------------------------------------------------------------
  文献值       = 2.95 meV  （Springer 2024 §8.5）
  → 换算 cm⁻¹   = 2.95 × 8.065544 = 23.793 cm⁻¹
  → 折合温度    = 34.2 K
  water-science 记载：284.7 J/mol（23.794 cm⁻¹）／ 34.3 K
  ★ 复算吻合：23.79 cm⁻¹ vs 23.794 cm⁻¹，34.2 K vs 34.3 K  ✅

--------------------------------------------------------------------------
(c) 与 H₂ 的对照：水里的这个能量差为什么「小得多」
--------------------------------------------------------------------------
  H₂  : 1.456 kJ/mol
  H₂O : 0.285 kJ/mol
  比值：5.12 倍

  → 原因：H₂ 是**线型分子**，只有两个转动自由度，转动能级间隔大；
         H₂O 是**非对称陀螺**，三个转动惯量都大，能级间隔小。
  → 后果（很关键）：H₂ 的 o/p 差 1.455 kJ/mol **大于其汽化热的一半**，
     所以液氢里的 o→p 自发转换会「自己把自己烧开」；
     而 H₂O 的这个差只有 0.28 kJ/mol，**对水的热性质影响很小**
     （这就是为什么水的 ortho/para 问题长期被忽视）。

==========================================================================
总 结（三句）
==========================================================================

  1. **「两个同款 / 两个异款」这个结构直觉，在核自旋层面是真的** ——
     4 个核自旋组合里，3 个对称、1 个反对称；
     但数出来是 **3 : 1**，不是 1 : 1。

  2. **判否它的不是比例，是「交换对称性」** ——
     ortho/para 能存在，前提正是两个核**全同**；
     HDO 因为两核不同而**没有** ortho/para。
     所以「H₂O 里两个 H 不相同」与「H₂O 有 ortho/para」互相排斥。

  3. ★★ **但假设里有一半是对的，而且比表面看起来更对** ——
     两条「1 : 1」（档案说的 H₂O ／ 主流说的液态水）**很可能是同一件事**。
     微灵视看到的不是幻觉，是真实存在的 ortho/para 效应；
     错的只是把**分子层的自旋关系**读成了**亚原子层的结构差异**。

  ★ 可执行查证：在微灵视档案里检索**重水 D₂O** 的观察记录 ——
     若给 1:1 则与 ortho/para 无关；若给 2:1 则强力支持「同源」。
