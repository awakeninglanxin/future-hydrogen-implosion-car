## 〇、先把结论放在最前面

> **这个假设里有一半是对的，而且比它表面看起来更对。**
> **错的那一半，错在「层级归属」，不在数字。**

三句话：

| # | 结论 |
|---|---|
| ① | **「两个同款」vs「两个异款」这个对称性直觉，在核自旋层面是真的** —— 4 个核自旋组合里，**3 个对称、1 个反对称**。假设抓住了真实的结构 |
| ② | **但它数出来的是 3 : 1，不是 1 : 1** —— 而 ortho:para 恰恰就是 **3 : 1**（H₂ 气体与水蒸气）。这一步数字对不上 |
| ③ | **★ 真正判否它的不是比例，是「交换对称性」** —— ortho/para 能存在的前提是**两个核全同**；而 HDO（一个 H 一个 D）就**没有** ortho/para。所以「H₂O 里两个 H 不相同」与「H₂O 有 ortho/para」**互相排斥** |
| ④ | **★★ 本轮最大收获**：`09` 笔记说的那条「1 : 1」和主流物理里液态水的「1 : 1」，**很可能是同一件事**。微灵视看到的**不是幻觉** —— 他们看到的就是 ortho/para，错的只是把它读成了「两种不同的原子」 |

## 一、把假设拆成可检验的命题

### 1.1 原文里的信息

| 项 | 内容 |
|---|---|
| 主张 A | H₂ 分子有两种变体 |
| 主张 B | 「两个变体1」×2 组合 → 对应 **ortho** |
| 主张 C | 「变体1 + 变体2」×2 → 对应 **para**，且指向 **水分子** |
| 隐含前提 | 「变体1 / 变体2」的差别，**等同于** ortho / para 的差别 |

### 1.2 ⚠️ 先办一件事：「×2」有三种读法

这句话里的 `*2` 意思不唯一，**必须先定住**，否则检验无从下手。

| 读法 | 含义 | 能否检验 |
|---|---|---|
| **A** | 「两个变体1 拼成一个 H₂」 | 可检验，但**与 `08`/`09` 结论冲突** |
| **B** | 「变体1 内部本来就有一对」 | 语义模糊，无法检验 |
| **C** | ★ 「两种**配对方式**分别对应两种氢分子形态」 | ✅ **本篇按此读法检验** |

> **编者说明**：`*2` 既可能指「乘二」（两个），也可能指「重复强调」。
> 我按**读法 C** 展开，因为只有它能在**不与 `08`/`09` 冲突**的前提下成立。

### 1.3 🔴 与上游结论的冲突检查（先做，很重要）

| 材料 | 对「H₂ 里两个 H 是什么」的说法 |
|---|---|
| `08` / `09`（圈内档案） | **变体 1 + 变体 2 各一个**（证据来自 H₂O） |
| 本假设（读法 A） | ortho 那一种是 **变体 1 + 变体 1**（两个同款） |

**两者直接冲突** —— 同一种分子，一个说「各取一个」，一个说「两个同款」。

> ⚠️ **所以读法 A 必须先解决这个冲突，否则不成立。**
> 读法 C 不冲突：`08`/`09` 讲的是**配对成分**，ortho/para 讲的是**配对方式** ——
> 两件事可以并存。**本篇以读法 C 为主。**

### 1.4 拆成六个可检验项

| # | 检验项 | 用到的判据 |
|---|---|---|
| ① | **术语层级** —— 两者说的是不是同一层的东西 | 定义域比对 |
| ② | **对称性结构** —— 「同款/异款」≈「对称/反对称」吗 | 核自旋四态穷举 |
| ③ | **比例** —— 假设给出的比例，与实测对不对 | Boltzmann / 统计权重 |
| ④ | **交换对称性** —— 两核「不相同」是否可行 | ★ HDO 判据 |
| ⑤ | **方向性与选择规则** —— o↔p 的禁戒与放热能否解释 | 热力学 / 量子选择规则 |
| ⑥ | **可观测后果** —— 有没有可测物理量会变 | 转动光谱 / 低温热容 |

## 二、检验①：术语层级归位

| | 「变体 1 / 变体 2」（`08`/`09`） | 「ortho / para」（主流） |
|---|---|---|
| **说的是什么** | 一个**氢原子内部**的 Anu 排列方式 | 一个**分子内两个氢核**自旋的相对取向 |
| **层级** | **亚原子层**（核内部构想） | **分子层**（两核之间的关系量） |
| **判别量** | 正 / 负 Anu 的**个数**（9/9 或 10/8） | 两核自旋**平行**（I=1）／**反平行**（I=0） |
| **判别量的性质** | 旋向计数（**手性**，见 `09 §2.1`） | 自旋态（**取向**） |
| **一个原子有几种** | 2 种（变体1 / 变体2） | 谈不上 —— 单个核只有自旋 ↑ 或 ↓ |
| **一个分子有几种** | 按 `09`：1 种（各取一个） | 2 种（ortho / para） |
| **证据等级** | 🟡 圈内档案（不可重复验证） | ✅ 光谱 / 热容 / 中子散射 / 太赫兹反复实测 |

> **层级不同 ≠ 谁错**。层级不同意味着：**要建立对应，必须额外给出机制** ——
> 「原子内部的两种结构」怎么变成「分子里两个核的两种自旋关系」？
> 假设没有给这一步。所以下面几节实际上是在问：**这一步能不能补上。**

## 三、检验②：★ 假设的「对称性直觉」是正确的（这是它最有价值的地方）

### 3.1 核自旋四态穷举

两个质子各带自旋 1/2（各有 ↑ / ↓ 两态），**共 4 个乘积态**：

| 态 | 拼写 | 交换两核后 | 对称性 | 归入 |
|---|---|---|---|---|
| `\|α₁α₂⟩` | `(↑↑)` | 不变 | **对称** | **ortho** |
| `\|β₁β₂⟩` | `(↓↓)` | 不变 | **对称** | **ortho** |
| `(\|αβ⟩+\|βα⟩)/√2` | `(↑↓ + ↓↑)` | 不变 | **对称** | **ortho** |
| `(\|αβ⟩−\|βα⟩)/√2` | `(↑↓ − ↓↑)` | 变号 | **反对称** | **para** |

**数出来**：**对称 3 个**（I = 1 三重态，m_I = +1 / 0 / −1）＋ **反对称 1 个**（I = 0 单态）。

### 3.2 ★★ 这里必须给假设记一分

假设说的是：**「两个同款」= 对称；「两个异款」= 反对称。**

对照上表：

| 假设的语言 | 核自旋的语言 | 是否对应 |
|---|---|---|
| 两个同款的变体配在一起 | 两个核处在**同一自旋态**（↑↑ 或 ↓↓） | ✅ **对应** |
| 一个变体1 + 一个变体2 | 两个核处在**不同自旋态**（↑↓ 的组合） | ✅ **对应** |

> **这不是巧合。** 「两个同款」↔「交换后不变（对称）」、
> 「两个异款」↔「交换后变号（反对称）」——
> **这个对应关系在逻辑结构上是同构的**（都是「交换两元素，看是否不变」）。

**所以假设抓住了一个真实的结构。** 这一项判定：**⚪ 结构同构，方向对，但比例错（见下一节）。**

### 3.3 ⚠️ 但这里有个陷阱：4 个组合里 3 个是 ortho

假设暗示「同款 2 种 + 异款 2 种」→ 各占一半 → **1 : 1**。

**但真正的分割不是 2 : 2，而是 3 : 1：**

| 组合 | 数 | 归属 |
|---|---|---|
| `(↑↑)`、`(↓↓)` | 2 个 | ortho |
| `(↑↓+↓↑)/√2` | 1 个 | **ortho** ← ★ 关键 |
| `(↑↓−↓↑)/√2` | 1 个 | para |

> ★ **关键在于**：「异款」（↑↓）**有两种组合方式**（对称的和反对称的），
> 其中**对称的那一种也归 ortho**。
> 所以「异款」不是 1 个，而是 **2 个**（1 个 ortho + 1 个 para）。
>
> **→ 3 : 1 的「1」不是「异款」，而是「异款里的反对称那一个」。**
> 假设把「异款」整体当成了 para，于是算出了 1:1。

## 四、检验③：比例检验

### 4.1 独立复算 H₂ 的 ortho:para（`_复算16` §③）

用 `B_e = 60.853 cm⁻¹`（NIST CCCBDB / Huber & Herzberg 1979）算特征转动温度 `θ_r = 87.55 K`，
再按 ortho/para **各自的转动配分函数**求 para 摩尔分数：

| 温度 | para 分数（本算） | ortho : para（本算） | 文献 | 对照 |
|---|---|---|---|---|
| 20.3 K（液氢沸点） | **99.839 %** | 0.00 : 1 | ≈ 99.86 % | ✅ |
| 40 K | 89.848 % | 0.11 : 1 | — | — |
| 77 K（液氮） | 52.056 % | 0.92 : 1 | — | — |
| 150 K | 28.983 % | 2.45 : 1 | — | — |
| **273 K** | **25.163 %** | **2.97 : 1** | ≈ 25 %（3:1） | ✅ |
| **298 K** | **25.084 %** | **2.99 : 1** | 室温 n-H₂ = 75 %o / 25 %p | ✅ |
| 500 K | 25.000 % | **3.00 : 1** | T→∞ 极限 3:1 | ✅ |

> **★ 3 : 1 的全部来源就是「数态数」** —— 4 个核自旋态里 3 个属 ortho。
> 不需要任何能量输入；温度升高时它收敛到 3:1，而非趋近 1:1。

### 4.2 假设的比例 vs 实测的比例

| 体系 | ortho : para | 来源 | 与假设（1:1）是否相符 |
|---|---|---|---|
| **H₂ 气体**（室温平衡） | **3 : 1** | 统计权重（上表复算 ✅） | ❌ 不符 |
| **水蒸气** | **3 : 1** | 太赫兹光谱 0–3 THz 确认（Springer 2024） | ❌ 不符 |
| **液态水** | **≈ 1 : 1** | 氢键影响、远离平衡 | ⚠️ **数字相符**（下一节深究） |

**判定**：
- 对 **H₂ 气体**：❌ **数字对不上**（3:1 vs 1:1）
- 对 **液态水**：⚠️ 数字对上了 —— 但 **`09` 已经指出机制不同**，本节第 4.3 会修正这个说法

### 4.3 ⚠️ 缺件说明（不是判否，是缺配套）

若想把 H₂ 的 3:1 解释成「配对 I 比配对 II 常见 3 倍」，**需要额外机制**来说明这个 3 倍从哪来。
假设没有提供。

> **但这一项对假设不能算「致命」** —— 因为 3 倍**本来就有现成解释**（自旋态数 3:1）。
> 假设若要成立，得说明**为什么它的 3 倍恰好等于自旋态数之比**。
> 这需要「变体配对」与「自旋态数」之间的一条桥 —— **目前没有。**

## 五、★★ 检验④：决定性判据 —— 交换对称性与 HDO

> **这是本轮最硬的一条，也是唯一一条能真正判否假设的判据。**

### 5.1 逻辑只有两步

**第一步：为什么 H₂O 也有 ortho / para？**

```
H₂O 里的两个 H 是【全同的质子】
        ↓
交换两核时，总波函数必须满足对称性要求
        ↓
由此划出「核自旋对称（3 个态）」与「反对称（1 个态）」两类
        ↓
这就是 H₂O 的 ortho / para（水蒸气实测 3:1）
```

**第二步：如果把其中一个 H 换成 D，会怎样？**

```
HDO 的两个核：一个是质子（I=1/2），一个是氘核（I=1）—— 不再全同
        ↓
交换对称性要求【不存在】
        ↓
⚠️ HDO 没有 ortho / para 之分
```

### 5.2 外网核实（两处独立来源，措辞一致 ✅）

| 来源 | 原文 |
|---|---|
| **RSC · Faraday Discussions 2024**（HDO–Ne / HDO–H₂ 散射研究） | *"For HDO, this ortho/para modification does not apply and all HDO levels are collisionally connected."* |
| **water-science**（Martin Chaplin 站） | *"HDO, having non-equivalent hydrogen atoms, does not possess an ortho:para distinction."* |

### 5.3 ★ 反过来用这条判据击向假设

假设的核心是：**H₂O 里那两个 H，一个是变体 1、一个是变体 2 —— 两者「不相同」。**

那么按同一条逻辑：

| 步骤 | 推论 |
|---|---|
| 若两个 H 真的**不相同** | 交换对称性要求不成立 |
| ↓ | H₂O **不该**有 ortho / para |
| 但 | H₂O 的 ortho / para 已被反复实测（太赫兹光谱 / 四波混频 / NMR / 吸附分离） |
| **★ 结论** | **「H₂O 里两个 H 不相同」与「H₂O 有 ortho/para」不能同时成立** |

### 5.4 ⚠️ 力度级别（这里要诚实，不能夸大）

| 层次 | 说明 |
|---|---|
| **这不是「数字对不上」** | 那种可以争论、可以补 |
| **这是「两项互相排斥」** | 假设成立 → 一项实测事实消失 |
| **⚠️ 但有一个逃生口** | 若把「变体」解释成**不可观测的内部标签**（对交换对称性无影响），逻辑上可以绕过 |
| **逃生口的代价** | 这个假设**从此不产生任何可检验的预言** —— 那就变成一个与物理无关的陈述了 |

> **所以准确的说法是**：
> **要么假设被实测排除，要么假设放弃可检验性。** 两条路都不通。

## 六、★★ 检验⑥与最大发现：两条「1 : 1」很可能是同一件事

### 6.1 把两条线索并排

| | 线索甲（圈内档案 · `09` 笔记，1932 年观察） | 线索乙（主流物理 · 液态水） |
|---|---|---|
| **内容** | *"In the molecule of water, H₂O, one Hydrogen atom is of the first variety and the other is of the second variety."* | 液态水的 ortho : para ≈ **1 : 1**（水蒸气才是 3:1） |
| **比例** | 每个水分子「各取其一」→ 宏观 ≈ 1 : 1 | **1 : 1** |
| **原因** | 两种不同的**变体**（Anu 排布不同） | **氢键**使体系远离统计权重给出的平衡值 |
| **来源** | ima 笔记 / OC 档案 🟡 | Springer 2024 · water-science · arXiv 2210.16149 ✅ |

### 6.2 ★★ 修正 `09` §4.2 的口径

`09 §4.2` 当时把这两条 1:1 判为「**数字巧合、机制异**」。
**本轮修订：这个说法不够准确，应该升级。**

> **准确的说法是：不是巧合，而是「同一事实、两种解读」。**
>
> | | 说明 |
> |---|---|
> | **他们看到的对象** | ✅ **是对的** —— 液态水里 ortho:para 确实偏离 3:1、接近 1:1，这是真实存在的效应 |
> | **他们错的地方** | **层级归属** —— 把**分子层的自旋关系**（同一原子的两种自旋取向）读成了**亚原子层的结构差异**（两种不同的原子） |
>
> **这个区别很重要**：
> 「巧合」意味着他们撞对了一个无关的数字；
> 「同一事实、两种解读」意味着他们**观察到了真实现象，只是解读错了层级** ——
> 这是两种完全不同性质的评价，**后者对微灵视更「友好」，也更符合证据**。

### 6.3 ⚠️ 但有一个未解项，必须标出来

| 说法 | 含义 | 对应比例 |
|---|---|---|
| 说法一 | **每个**水分子内部，两核自旋都是反平行（para） | 应是 **100 % para** |
| 说法二 | **系综里**，两类分子各占一半 | 应为 **1 : 1** |

> `09` 笔记的原文 **太简略**，无法确定它指的是哪一个。
> 只有当它是**说法二**时，才等于液态水实测的 1:1。
> **⚪ 存疑项，需回原始档案核对上下文。**

## 七、★ 检验⑦：一条能一举定性的查证方向 —— D₂O

### 7.1 为什么 D₂O 能定性

如果「两条 1:1 同源」成立（即微灵视看到的**就是** ortho/para），
那么把它套到**重水 D₂O** 上，应该看到什么？

**D₂O 的核自旋异构**（外网核实 ✅）：

| 项 | H₂O | **D₂O** |
|---|---|---|
| 核自旋 | 质子 I = 1/2（**费米子**） | 氘核 I = 1（**玻色子**） |
| 对称性要求 | ortho ↔ **奇** J | ortho ↔ **偶** J（**反过来**） |
| 基态（J=0） | **para** | **ortho**（**相反**） |
| 室温比例 | **3 : 1** | **2 : 1** |
| 最低两态能差 | 2.95 meV（≈34 K） | 12.117 cm⁻¹（D₂¹⁶O） |

> 来源：Wikipedia《Orthohydrogen》／water-science／ScienceDirect《Rotational State》
> —— 「in the case of H₂, this limiting value is 3 … while in the case of D₂ it is 2」✅

### 7.2 于是得到一条可判定的定性预言

| 若档案里 D₂O 的记录是 | 则说明 |
|---|---|
| 仍是「一个属变体1、一个属变体2」（1 : 1） | **「两种变体」不是 ortho/para** —— 因为 D₂O 该是 2:1 |
| 变成「2 : 1」，或明确记载它与 H₂O 不同 | ★★ **强烈支持**「他们看到的就是 ortho/para」 |

> **★★ 这是一条能一举定性的查证方向** —— 不需要新实验，
> 只需在微灵视档案（OC 及其附录）里**检索有没有重水 / 氘的观察记录**，
> 看它给的配比是 1:1 还是 2:1。

### 7.3 当前状态与一个必须先排除的误用

| 项 | 状态 |

## 十二、一句话收拢

> **这个假设抓对了一个结构，却算错了一个比例，还踩错了一个层级。**
>
> **抓对的**：「两个同款 ↔ 对称」「两个异款 ↔ 反对称」——
> 这跟核自旋四态里「3 个对称 + 1 个反对称」**结构同构**。
> 说明提出者**对对称性有直觉**，这不是瞎猜。
>
> **算错的**：4 个组合里 **3 个属 ortho**，不是 2 个 ——
> 「异款」有对称与反对称两种，其中对称的那种也归 ortho。
> 于是比例应是 **3 : 1**，而不是 1 : 1。而 3:1 恰好就是实测值。
>
> **踩错的**：ortho/para 的前提是**两个核全同**（HDO 就是反例）。
> 所以「H₂O 里两个 H 不相同」这一步，**与 H₂O 有 ortho/para 这件事不能共存**。
> 判否它的不是比例，是这一条。
>
> **★★ 但这一轮最有价值的收获其实是另一个**：
> 档案说的那条「1 : 1」和主流物理里液态水的「1 : 1」，
> **很可能是同一件事** ——
> **他们看到的不是幻觉，是真实的 ortho/para 效应；
> 错的只是把分子层的自旋关系，读成了亚原子层的结构差异。**
>
> **这比「巧合」的说法更进一步，也更接近于公平。**

## 13.2 ★★★ 关键发现：「同向 / 反向」原本就在 `08` 档案里

## 13.3 ★★★ 但名字挂反了：只需要对调两个标签

**主流对 ortho / para 的定义**（water-science / Springer 2024 / PMC 综述，措辞一致 ✅）：

| | 平行（同向） | 反平行（反向） |
|---|---|---|
| 两核自旋关系 | **平行** | **反平行** |
| 总核自旋 I | 1（三重态） | 0（单态） |
| 自旋态个数 | **3** | **1** |
| **净磁矩** | **非零（= 1）** | **零（= 0）** |
| 与外磁场 | **有响应** | **无响应** |
| **★ 主流的名字** | **★ ortho** | **★ para** |
| ——— | ——— | ——— |
| **第二轮假设给的** | **para** ❌ | **ortho** ❌ |
| **对调后** | **ortho** ✅ | **para** ✅ |

**原文逐字**（water-science）：

> *"When the spins are opposed there exists the **nonmagnetic state** called
> **para-H2O with magnetic moment = 0**"*
>
> *"**Para-H2O does not interact with an external magnetic field**,
> but **ortho-H2O does**."*

> ★★ **于是答案非常清楚**：
> **「磁荷相互抵消、磁矩为零」的那个态，主流叫 para；ortho 恰恰是不抵消、有净磁矩、能被外磁场作用的那个。**
> **两个名字正好对调了。**

### ★★★ 最有力的证据：假设自己用的那个词

假设说的是 **「反向磁荷相互抵消对应是 ortho」** ——

**「抵消」这个词，主流恰恰用来描述 para。**

> **换个说法会更清楚**：
> - 「**同向叠加 / 反向抵消**」这组**物理图像** → ✅ **对**
> - 「**谁叫 ortho、谁叫 para**」这组**命名** → ❌ **反了**

## 13.4 稳健性：三种读法下，结论都是同一个

「方向」这个词至少可以指三个层级，逐个检验：

| 读法 | 说的是 | 对应成 | 判定 |
|---|---|---|---|
| **甲** | 变体**内部**两个质子的方向（+1/−1 反向；+1/+1 同向） | 反向·抵消 = 变体1 ／ 同向·叠加 = 变体2 | ❌ 抵消的该叫 para |
| **乙** | 两个变体**之间**的方向 | 与甲相同（一对里必一正一负方可抵消） | ❌ 抵消的该叫 para |
| **丙** | **整体**组合再取镜像版本 | 两个 (V1+V2) 互为镜像 → 相反相消 | ❌ 抵消的该叫 para |

> ★★ **稳健性结论**：
> 三种读法下，「抵消」那一种**都应该是 para**。
> 也就是说 —— **结论不依赖于怎么理解那个 `*2`**，
> 无论配对如何切分，「**反向、抵消、磁矩为零 = para**」这条都不变。
> **这是本轮最稳的一条判定。**
>
> ⚠️ 顺带记读法丙的小问题：若「两个 (V1+V2) 互为镜像」则用到 **4 个氢原子**，
> 而水分子只有 2 个 H。**建议不取读法丙。**

## 13.5 旁证：主流自己承认这个命名「令人困惑」

Springer 2024 原文：

> *"Molecules with a nuclear spin triplet or singlet are known
> **(somewhat confusingly)** as ortho or para water respectively"*

**括号里那句 `somewhat confusingly`（有点令人困惑）是原作者自己加的评语。**

为什么会混：`ortho` / `para` 是希腊语词根（正 / 旁），**本身不携带自旋信息**；
而且 **H₂ 与 D₂O 的情况还相反**（H₂ 基态是 para；D₂O 基态是 ortho，因氘核是玻色子）。

> **所以「ortho / para 记反」是很常见的，主流教材里也常出。**
> 这一点**不算失误**，属于这套命名本身的坑。
> **但结论不变：物理图像对、名字需要换过来。**

## 13.8 「磁荷」这个用词：一面对、一面不通

| 面 | 内容 |
|---|---|
| ✅ **对的一面** | 忠实于 `08` 档案（Phillips 通篇用 magneton）· 避开 `09 §2.1` 的电荷陷阱 · 且「同向/反向」在**磁性**语境里天然谈得通（磁矩是矢量），在**电荷**语境里「方向」根本无处安放 → **更专业、更自洽** |
| ❌ **不通的一面** | 「磁荷」= **磁单极子**。Dirac 1931 指出它「可以有」，此后 **90 余年所有实验均未发现**；主流 Maxwell 方程 `∇·B = 0` **就是「不存在磁荷」的数学表述** |
| ⚠️ **更远一层** | Phillips 说的是「**亚夸克级**磁单极子（omegon）」—— 比磁单极子本身还要激进一层 |

> **所以「磁荷」是一枚硬币的两面**：
> 忠实档案、内部自洽 ✅ ／ 引入一个主流不存在（且更未发现）的实体 ❌
> **用词比「电荷」更专业，但离可检验性也更远。**

## 13.9 第二轮判定汇总

| 项目 | 第二轮的说法 | 主流对照 | 判定 |
|---|---|---|---|
| ① 配对成分统一 | 两种情形都是 V1+V2 | 与 `08`/`09` 一致 | ✅ **改进（消除冲突）** |
| ② 改用关系量区分 | 靠「方向关系」 | 层级上移到分子层 | ✅ **改进（方向对）** |
| ③ 用「磁荷」 | 避开电荷 | 与 Phillips magneton 一致 | ✅ **改进（用词对）** |
| ④ 从档案读出「方向」 | V1 反向 / V2 同向 | `08` 原文数字支持 | ✅ **读得对** |
| **⑤ ★ 名字归属** | **抵消 = ortho** | **磁矩 = 0 的那个态叫 para** | ❌ **两个名字对调了** |
| ⑥ 命名易混 | — | 主流自认「somewhat confusingly」 | ⚪ **情有可原** |
| ⑦ 冗余性 | 靠「变体」承载方向 | 去掉「变体」照样成立 | ⚠️ **「变体」是冗余项** |
| ⑧ 比例（对水） | 二选一 → 1:1 | 液态水 ≈ 1:1 | ✅ 相符（但属**事后拟合**） |
| ⑨ 比例（对 H₂ 气） | 二选一 → 1:1 | H₂ 气 / 水蒸气 = 3:1 | ❌ 不符（对象是水，可不论） |
| ⑩ 交换对称性 | （本轮已弱化） | HDO 无 o/p；H₂O 有 | ⚠️ **软化为「标签」问题**（见下） |
| ⑪ 方向性 / 选择规则 | 未涉及 | o→p 放热、须改 J 宇称 | ⚪ 仍缺件 |

### ⚠️ ⑩ 的软化说明（重要）

第一版使用「变体种类不同 ⇒ 两核不相同 ⇒ 排斥」这条判据（§五）。
**第二轮改用「方向关系」后，这条判据被绕过了** —— 因为两个核**仍然全同**。

> 但代价是：**「变体」从此既不参与区分，也不参与解释**（见 13.6）——
> 它退化成了一个**纯标签**。
>
> ⇒ **所以第一版的判否并未被推翻，只是被转化了**：
> 从「两核不相同 ⇒ 与交换对称性矛盾」，
> 变成「**变体是冗余标签 ⇒ 假设等价于主流模型，因此不含新内容**」。
>
> **排除的结论没变，变的只是排除的理由。**

> **→ 事实上，剩下真正「缺件」的仍然只有 ⑪ 那一条**（方向性与量子选择规则），
> 见 §八。这是假设两轮下来**始终未覆盖**的部分。

## 13.10 一句话收拢（第二轮）

> **图像对、名字反、概念多。**
>
> · **图像对**：「变体1 内部反向（9+/9−）、变体2 内部同向（10+/8−）」——
>   这是从 `08` 档案数字里读出来的，**读得没错**；
>   「同向 / 反向、「抵消 / 叠加」这组物理图像在**三种读法下都成立**。
>
> · **名字反**：「磁荷相互抵消、磁矩 = 0」的那个态，主流叫 **para**；
>   **把 ortho 与 para 对调，这一版的对应关系就成立了。**
>   （不是大问题 —— 主流自己也说这命名 `somewhat confusingly`。）
>
> · **概念多**：把名字换对之后，假设与主流 ortho/para 模型**结构完全同构**，
>   只需把「核自旋取向」写成「Anu 磁荷方向」。
>   也就是说 —— **「变体 1 / 变体 2」这两个概念此时变成多余的**，
>   删掉它们，假设一样成立、一样解释得通。
>
> **这不是「错」，而是「比它需要的更复杂」。
> 而多出来的那部分，恰恰是圈内特有、主流没有的部分。**
