# 一、电池本体：Joe 定型的 Mark III 结构

这是三代里唯一被认定的成功版本（Mark I 蒸汽思路、Mark II 平板式都失败）[citation:1]。

**材料硬指标**
- 全部 **316L 奥氏体不锈钢，无磁**。判据：用磁铁试，可以被轻微吸引，但**绝不能吸住并吊起磁铁自身重量**
- 焊缝用 TIG 惰性气体焊，不能用氧化性气体[citation:2]
- 自己卷圆筒时**只在顶部、底部、中间点焊（stitch weld）**，未焊的缝隙"是大量气体和能量逸出的地方"[citation:2]

**尺寸（Mark III 标准）**[citation:4][citation:1]
| 部件 | 规格 |
|------|------|
| 中心阴极 | 1″ 直径，8″ 高，**接线从底部穿出并绝缘**（据说输出翻倍） |
| 中性筒 | 3 个，2″、3″、4″ 直径，**高度与阴极完全相同** |
| 外壳（阳极） | 3mm 不锈钢厚壁容器 |
| 顶部 | 圆锥/穹顶，用于把"能量"汇聚到出口 |
| 锥角 | 60°–90°，316L 最优 **57°**；另说 52°–54° 更好 |
| 内部上下留空 | 不小于 1″ |
| 最外中性筒→外壳 | 0.5″–2″ |

**两个极易被忽略的致死细节**
1. **所有筒顶端必须严格齐平**——否则水面弯液面失效，水会从一个格流到另一个格[citation:3]
2. **绝缘垫用实验室纯胶塞（无孔，酸瓶塞那种），平面侧贴筒壁而非圆面侧**，目的是防止沉渣积存造成短路和点蚀；上下各 3 个，内缩 5mm，略大以抗震；另切槽 3 个从下方托住最外中性筒[citation:4]

Joe 还坚持**另配一个独立的"充水缸"**，车用电池只装充好的水——因为电解产生的表层沉渣会短路车用电池[citation:4]。

# 二、水与"充电"：90% 的人死在这一步

这是全流程中最核心、也最反直觉的部分。

**用水**
- Alex Schiffer 主张 "juvenile water"：**未受人为污染的自然山泉源头水**，在泉水涌出处取，不要经过管道
- 退而求其次：涡流（vortex）处理、摇动、过滤来"激活"水[citation:3]
- Joe 首次成功用的是雨水 + 少量柠檬汁，把 pH 调到约 6.3，5 分钟就有大量气体[citation:1]

**电气参数**
- 目标电流 **1A @ 12V**（Alex 认定这是理想电解条件）；用纯水的耐心玩家可以低到 **50mA**[citation:3]
- 12V 下要走到 1A，pH 大约要压到 **2–3**[citation:3]
- 极性死规矩：**负 → 中心筒底部，正 → 最外筒顶部**，永远不能反[citation:3]

**水位（关键）**
只加到**刚好与筒顶齐平，绝不多加**。目的是形成"被金属筒隔开的独立水格"，顶部才是做功的地方[citation:3]。

**通电纪律**
每次通电 **不超过 5 分钟**。原文骂得很直白：失败者的特征就是让电池连着几天不停跑 20A 以上，把水烧成蒸汽、蚀刻筒壁、最后得到一桶沉渣——**这种损伤无法抛光修复，只能整组扔掉重做**[citation:3]。Orgone 比电滞后约 30 秒，一分钟内就能判断状态。

## 三个阶段判据（最实用的部分）

**Stage 1 — 普通电解**
- 小气泡，活动最剧烈处在中心阴极附近，向外逐格递减
- 断电后活动很快停止，水变清[citation:3]

**Stage 2 — 已"seed"，未"breed"**
- 气泡变大，白色雾状小泡变少/更透明
- 气泡分布变均匀，不再只围着中心筒
- 断电后气泡**留存数分钟**而非数秒
- 水面呈"釉面"光泽，弯液面变高（表面张力上升）
- 可能有褐色漂浮物——是杂质析出，用纸巾贴水面吸掉即可
- 缸底无沉渣、水清澈[citation:3]

**Stage 3 — 可以开车的最低门槛**
- 通电 **30 秒内**，全表面涌出大量纯白气泡
- 在气泡覆盖水面之前，能看到**同步的旋转与脉动前沿**：约 **2 次/秒**脉动、约 **2 秒/圈**顺时针旋转（用荧光灯看更容易，100Hz 频闪会把水面"频闪"出来）
- 决定性证据：**断电过夜，第二天大部分气泡仍浮在水面**——Stage 1/2 的气泡几分钟就没了[citation:3]

**自检手段**：断电静置 24 小时后测两极电压，**活细胞约 1V**；Stage 1 只有 0.1–0.2V。注意表笔材质和电池效应会严重干扰读数[citation:3]。

**特别警告：Stage 3 特种水**——如果不想腐蚀非不锈钢/玻璃容器，可以用不加电解质的纯"juvenile water"，但需要 **60–100V、约 1A** 的电源，且可能要等 **3 周以上**[citation:3]。

## 三条"一碰就死"的禁忌

1. **绝不能短路任意两个筒**——婚戒、表笔、导线都算。一旦发生，1 分钟内回不到 Stage 3，就**只能全部拆解重新抛光、清洗、再充**（原文：这是你唯一的选择，我不是开玩笑）[citation:3]
2. **绝不能给完全密封的电池充电**——会爆炸。从头到尾**不需要任何气密**[citation:3]
3. **别玩点火爆气泡**——Alex 自述亲手炸死了一个用了 7 个月的心爱测试电池，退回 Stage 2 整整 4 天[citation:3]

时间预期：几天到一周到 Stage 2，通常再几天到 Stage 3；最坏情况 **4 周**，期间电池必须静置不受打扰[citation:3]。

# 三、装车：机械部分

**传输管（cell-to-engine tube）**[citation:17][citation:18]
- **1″ 外径（24mm）铝管，内径 3/4″（20mm），壁厚 1/8″**
- **铜管绝对不行**——电解作用会污染电池或污染自身[citation:18]
- 越短越好，弯折必须平滑渐进无变形，**尽量减少水平段，禁止 U 形下弯**（Orgone 被认为向上走，强迫它改向下会漏能）
- 管外包保温/绝缘层，全程不得接触车身任何金属
- **锥内到管口的内径必须由 20mm 平滑渐变到 24mm，无突变**；内表面全抛光、流道内无任何阻碍——这是"把能量聚成束打进铝管"的关键区域[citation:17]
- 管与电池顶部的压缩接头必须**金属对金属拧紧到扭不动**，且不能用密封胶或生料带[citation:18]

**电池安装位置**
- **尽可能低**，让能量自下而上流向盲塞[citation:17]
- 反例警示：有人把电池装在车顶上方、管路严重下坡接发动机——这是"错误安装的典范"[citation:17]
- 固定：用那根 1/2″ 负极螺栓穿过地板固定，外加两个喉箍；外裹鼠标垫/潜水衣料减震，防止电池产生独立于发动机的共振
- **外壳带正电，任何部位碰到车身金属就得重新充电**

**选车**
原文直言：现代前驱、电控喷射、可变气门、涡轮、双顶置凸轮的紧凑四缸车，**一次改装成功的概率极小**。必须**负接地**系统（正极接地的老车别改）。

# 四、装车：电气部分

- **负极**：中心筒那根 1/2″ 螺栓 → 车身/发动机体。钻孔处必须**除漆除隔音层**，两侧各加**星形垫圈**保证低阻
- **正极**：接在**铝管的最末端**——具体做法是塞在 4″ 氯丁橡胶套下面，用不锈钢蜗轮喉箍压紧。然后经 **5A 保险丝**接到"点火 ON"档，只在钥匙运行位供电[citation:18]
- 功耗：1A × 12V = **12W**（长途热天仍会让电池升温）
- **停车维持**：Joe 早期用 **1.5V 电池**（负接阴极、正接外壳）解决过夜放电；后期设计不再放电就不需要了[citation:1]。Alex 建议用 **0.25A 涓流**，即正极串一个约 **3Ω / 4–5W 线绕电阻**——电阻会发热，必须妥善固定防火
- Moe-Joe 官网的说法是：**始终在电池正负极跨接 1.5V 电池**以保持电位

# 五、接口：从化油器到盲塞（两阶段）

## 阶段 A ——
