## 一、① 单质氢（原子态氢 H·）—— 真实，但留不住

### 1.1 它是什么

**不是氢气**。氢气是 H₂（两个氢原子成键的分子）；**单质氢 / 原子氢**是**孤立的 H 原子**（文献里写作 H· 或 H₁）。

> ⚠️ 中文「**单质氢**」这个词**有三个意思**，是本话题最大的坑：
> - **义 1 · 元素态氢**（相对「氢化合物」而言）→ 指的其实就是 **H₂ 气体**；
> - **义 2 · 原子态氢**（相对「分子态氢」而言）→ 指 **H·**；
> - **义 3 · 氢原子的两种结构变体**（Variety 1 / Variety 2）→ ★ **2026-09-11 新增**，
>   来自 ima 笔记《单质氢的两种变体》，属**微灵视档案**（非主流物理）。
>   **详见 `08_单质氢的两种变体_微灵视MPA档案.md`**。
>
> 🔴 **注意：义 3 与本文件的「单质氢」不是同一件事。**
> 本文件 §一 讲的是**义 2（原子态氢 H·）**；
> 义 3 讲的是**同一个氢原子内部**有两种 Anu 排列 —— **层级不同，不可混用**。
>
> 📌 三个义项的层级：`H₂（分子层）` → `H·（原子层）` → `变体（原子内部结构层）`

### 1.2 关键数据（都是可查的经典物理）

| 量 | 数值 | 说明 |
|---|---|---|
| H₂ 解离能 | **436 kJ/mol**（文献亦见 422 / 435 / 458.5 的不同取法） | H₂ → 2H·，**吸热** |
| 原子复合放热 | **≈ 436 kJ/mol ≈ 218 kJ/g** | 2H· → H₂，**放热** |
| 原子氢能量密度 | **≈ 218 MJ/kg** | 比 H₂ 燃烧热（HHV 142 MJ/kg）还高——**已知最强的非核化学能密度** |
| 复合温度 | **3,500–4,000 °C** | 工业"原子氢焊"就靠这个 |

### 1.3 怎么产生、怎么用

- **产生**（三种成熟手段）：① **高温**——但解离是极陡的：2000 K 只有约 0.08% 解离，3000 K 约 7.8%，4000 K 约 62%，5000 K 约 95%；② **低压放电**；③ **汞灯 253.7 nm 光解**（光敏解离）。
- **利用**：**原子氢焊（Atomic Hydrogen Welding）**——Langmuir 1927 年发明。H₂ 从两个钨电极间的**电弧**中穿过 → 解离成 H·（**把电弧的能量"存进原子里"**）→ 喷到工件表面，原子**复合**放热 → 局部 3,500–4,000 °C，比普通气焊高得多，还能顺带把氧化物还原掉。

### 1.4 死穴（这也是它最容易被误读的地方）

> **解离吸热 = 复合放热。** 原子氢是**储能介质**，不是**能源**。
>
> 你要先花 436 kJ/mol 把它拆开，才能在别处拿回 436 kJ/mol。**没有任何净增量。**
>
> 而且它**在常温常压下根本存不住**：原子会瞬间寻找同伴复合、放热，进而热失控。工业上它只存在于**电弧/等离子体附近那几厘米**里，**从不用于储能**。

**所以对 Joe Cell 那一档的判断是**：
- "原子氢能量密度更高" → **成立**（教科书数据）；
- "因此 Joe Cell 能白拿一份额外能量" → **不成立**（先存后取，且常温存不住）；
- "Joe Cell 产出了原子氢" → **无任何测量证据**（无光谱、无 EPR/顺磁共振数据；且常温电解槽里原子氢寿命毫秒级，不可能被带到做功阶段）。

## 二、② HHO / 布朗气 / 富吉先生的 HDCC —— "商品名"之争

### 2.1 圈内主张怎么说

产自 ima 知识库与三篇《独角兽 HHO》的**圈内框架**（忠实转述）：

| 主张 | 出处 |
|---|---|
| 电解水得到的**不是 H₂+O₂ 的简单混合**，而是"**氢氧原子纳米气体**"，H、O 按 2:1 "**平稳相处、和睦相混**" | 《独角兽 HHO 之一》 |
| "**不爆不燃**"：火柴点不着，烟头凑几秒才点燃，火苗 100–400 mm | 同上 |
| **燃烧温度随被燃物改变**：烧铝只到 660 °C；烧钨可达约 6,000 °C，"至今测不出上限" | 同上 |
| **内爆**：电解产气体积比 1:1859；气体"内爆变回水"时体积骤缩成负压 | 同上 |
| 用途极广：焊石英（省燃料 75%）、处理废水、**制造真空**、**消化核废料**、氢分子医学 | 同上 |
| 升级形态 **HDCC（High Density Charge）**："高密度电子群（~10¹¹ 个）形成的高密度电场、基于该电场的电磁（~10¹⁹ eV）"，与杂质原子核一起"以**等离子体状态**存在" | 《独角兽 HHO 之二》 |

### 2.2 主流判定怎么说

| 主流结论 | 依据 |
|---|---|
| **HHO / 布朗气 = oxyhydrogen（氧氢混合气）= 2H₂ + O₂**，没有新物种 | 化学常识；维基《Oxyhydrogen》 |
| "**Brown's gas**" 原本特指**共管式**电解槽的输出——H₂ 与 O₂ 在**同一根管**里出来、**不分离**；分开供气的**不算** Brown's gas。**布朗的"分别"在这里，不在"新物质"。** | CheMEurope / 维基 |
| "**HHO**"这个词由**边缘物理学家 Ruggero Santilli** 推广，其"**magnecules（磁核）**"不是主流理论 | 维基 |
| 围绕它的**夸大主张**（中和核废料、促种子发芽等）被归为**边缘科学/伪科学** | 维基《Oxyhydrogen》 |
| 车载电解当燃料或助燃剂的**决定性反驳**：**拆水耗能永远多于烧气回收**；且车载电解产气量相对发动机耗气量**极小** | Popular Mechanics 2008；维基 |

### 2.3 三个争议点的"翻译"

**(a) "内爆"是真的吗？—— 真的，但被误读了**

```
燃烧瞬间：2H₂ + O₂ → 2H₂O（蒸汽）    3 体积气 → 2 体积蒸汽（还因高温膨胀，先不缩）
冷凝那一刻：2H₂O（蒸汽）→ 2H₂O（液）  体积骤缩 ≈ 1,860 倍  ← "1,859 倍"来自这一步
```

- "1,859 倍"这个数字**方向是对的**（液化的体积收缩是真的）；
- 但它是**"收缩出空间"**，**不是"炸出能量"**；
- "内爆能量是爆炸的 4 倍" → **无独立验证，且与热力学直冲突**（同一反应的焓变固定）。

**(b) "温度随被燃物改变"怎么解释？**

主流解释很朴素：**火焰"把热量交给多少物质、交得多快"不同**——铝导热快、热容大、表面有氧化层；钨/耐火砖反之，且表面能吸附氢、促进原子复合。**不是气体本身有"智能温控"。**

**(c) 富吉一纯的 HDCC（日本发明人）**

公开履历与时间线（**均为单方来源，无第三方复现**）：

| 年份 | 事件 |
|---|---|
| 1996 | 开始水电解制氢设备商品化研究 |
| 1999 | 在**日立制作所**完成首台 HHO 气体发生装置（用于切割机） |
| 2010 | 燃烧辅助装置获专利（JP 2010-272864）；内燃机系统专利（2010-272865） |

| 2017 | 宁波/常州/青岛 大唐、华能 大型锅炉搭载试验；三菱发动机搭载试验 |

## 三、③ 氢气 + 氧气（H₂ + O₂）—— 正规化学里的那瓶气

这就是**分子态**的氢与氧混在一起。**它是 HHO 在主流化学里的正式身份。**

| 性质 | 数值 |
|---|---|
| 化学计量比 | **2 : 1**（H₂ : O₂，与水的组成同比例） |
| 自燃温度 | 约 **570 °C**（常压化学计量） |
| 火花点火能 | 约 **20 μJ**（极低，静电即可能点燃） |
| 可燃/爆炸范围 | 约 **4% – 95%** H₂（体积） |
| 燃烧放热 | **241.8 kJ/mol**（每 mol 被烧的 H₂） |
| 火焰温度 | 化学计量时最高，约 **2,800–3,000 °C**（过量气或掺氮都会降低） |
| 制法 | 电解水（天然得到化学计量比）；或分路供气 |
| 典型用途 | 氧氢炬切割/焊接、石英加工、玻璃火抛光、光纤预制棒 CVD |

> 📌 **一个容易被忽略的工程细节**：实际切割/焊接时，氧氢炬常按 **4:1 或 5:1**（而非 2:1）供气，为的是**避免氧化焰**——这也说明"2:1 是唯一正确比例"并非工程事实。

## 四、三者最容易混淆的三个点（"完善认知"的核心）

### 坑 1：「单质氢」一词**有三个意思**（★ 2026-09-11 由两义修订为三义）

| 用法 | 实际指 | 若 Joe Cell 指这个 |
|---|---|---|
| **义 1 · 元素态氢**（相对"氢化合物"） | **H₂ 气体** | ✅ 成立——就是普通电解氢 |
| **义 2 · 原子态氢**（相对"分子态氢"） | **H·** | ⚠️ 物理上确有更高能量，但 Joe Cell **无证据、工程上不可行** |
| **义 3 · 氢的两种结构变体**（★ 新增） | 氢原子内部的 **Anu 排列差异** | ⚪ **Joe Cell 的语境里从未出现这层主张**（见 `08`） |

**同一个词，三种指涉，三个结论。** 讨论"Joe Cell 产生单质氢"时，**必须先问清是哪一义**——
这正是 ★ 报告 §命题① 与 `04` 给出的"部分成立"判读的由来。

> **义 3 的补充说明**：义 3 来自 ima 笔记《单质氢的两种变体》，
> 是**微灵视（clairvoyant）档案**里对氢原子内部结构的两种画法
> （变体 1 = 9 正/9 负；变体 2 = 10 正/8 负）。
> **它不主张能量增益**，只主张结构如此 —— 与义 1/义 2 的"能量"话题**不在一个维度上**。
> 详见 `08_单质氢的两种变体_微灵视MPA档案.md`。

### 坑 2：「HHO」是**商品名/圈内名**，不是化学式

化学上写不出 "HHO"：
- **水**是 H₂O；
- **氢氧混合气**是 2H₂ + O₂；
- **"HHO"** 只在**默认接受"它是一种新物种"这个前提**时才成立。

**用 "HHO" 讨论，等于先接受了圈内的前提。** 这就是为什么主流材料一律写 **oxyhydrogen**。

> 📌 **★ 2026-09-11 补充（编者）**：
> **HHO 也可以就是「纯氢与纯氧按摩尔比 2:1 的混合物」** ——
> 这一定义**与主流化学完全一致**（电解水 `2H₂O → 2H₂ + O₂`，H₂:O₂ 恰为 2:1）。
> 换句话说：**「HHO」这个名字虽然不规范，但它指的东西可以完全不神秘** ——
> 就是电解水产出的那瓶 2:1 氢氧混合气。
> 这条表述（老师提出）是本项目「祛魅」口径的一个**正面样板**：
> **不用反驳，直接给正确定义即可。** 详见 `Lyne原子氢技术/04` §2.1。

### 坑 3：「内爆」≠「炸出能量」

内爆是 **H₂ + O₂ → H₂O 相变的体积收缩**（气 → 液）。它**能产生负压、能让大气压做功**，但：
- 负压的势能来自**蒸汽冷凝**；
- 冷凝的潜热来自**燃烧**；
- 燃烧的氢来自**电解**；
- 电解的电来自……**你把账算到最前面，一定是亏的。**

**"借助大气压做功"本身不违反能量守恒**（大气压确实在推），但**整条链的净额仍然是负的**——这两句话都对，且不矛盾。

## 五、三条可操作的区分判据（怎么当场验）

### 判据 1 · 法拉第上限：**1 Ah → 627 mL HHO**

```
法拉第：  1 mol H₂ 需 2 mol e⁻ = 2 × 96,485 C = 192,970 C = 53.6 Ah
则：      1 Ah → 22.4 L / 53.6 = 0.418 L H₂
HHO 总量：H₂ : O₂ = 2 : 1 → 每 2 mol H₂ 带 1 mol O₂ → 总气量 = 0.418 × 1.5 = 0.627 L
∴  1 Ah → 627 mL HHO（STP 理想值）
```

**电荷口径 → 能量口径**（这一步是全部"超法拉第"判定的枢纽）：

```
627 mL/Ah 是「电荷口径」，与电压无关；
换算成 mL/Wh（能量口径）时必须除以单槽电压 u：
    mL/Wh  = 627 / u
```

| 单槽电压 u | 1 Wh 最多产多少 HHO（100% 效率） | 说明 |
|---|---|---|
| **1.229 V** | **510 mL/Wh** | 可逆电压（理论极限） |
| **1.481 V** | **423 mL/Wh** | 热中性 HHV ← **判超法拉第用这一条** |
| 1.8 V | 348 mL/Wh | 商用碱性槽（好） |
| 2.2 V | 285 mL/Wh | 商用碱性槽（差） |
| 4.0 V | 157 mL/Wh | 老旧/极差设备 |

> 🔴 **2026-09-11 更正**：本节此前写「12 V 单槽 = 52 mL/Wh」「串联槽 = 313 mL/Wh」，那是把**串联 n 槽的总电压**误代**单槽电压**。真实碱性槽**每槽 1.8–2.2 V**，且总电压再高也不改变每 Wh 产气上限（n 在分子分母里约掉）。故上限应为 **423–510 mL/Wh**，旧文 52 / 313 两个数**均不成立**。

> ✅ **当场判据**：任何"产气量"数字，先换算成 **mL/Wh**，和上表比。**超过上限 = 输入漏算或测量假象。**

**★★ 由此得一条可直接反推的判据**：

```
        u_cell = 627.2 / (cc/Wh)        ← 与串联槽数无关
合理区间：1.5 ~ 4 V（工业最差的旧设备约 4 V）
落在区间外 → 该"cc/W"表述有误，或 W 不是电功
```

### 判据 2 · 光谱 / EPR：**直接测"有没有原子氢"**

- H· 与 H₂ 的**发射/吸收谱不同**；原子氢有**未成对电子**，可用 **EPR（电子顺磁共振）** 直接测；
- **至今没有一份 Joe Cell / HHO 材料拿出这种数据**——这是"产生单质氢"主张最直接的软肋。

### 判据 3 · 热力学：**"输出 > 输入"必先找出漏算项**

- 圈内文档的通用结构是"**车载电解、边走边产气**"——**把发电机负载藏进发动机里，账面上就"看不见"了**（★ 报告 §3 已算过：制氢约 50 kWh/kg，烧回约 15.8 kWh，净 **−34 kWh**）；

**★ 从油耗反推（上界假设，独立佐证）**

**★★★ 一次问清（0 成本，问完即定案）** —— 向主张方要四个数：

```
① 测量时的槽电压 U（V）
② 测量时的电流 I（A）
③ 计量时长 t（min 或 h）
④ 该时段产气量 V（cc），以及 用什么方法测的
```
